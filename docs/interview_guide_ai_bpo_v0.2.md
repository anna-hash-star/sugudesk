# AI BPO ニーズヒアリング インタビュー設計 v0.2

> SuguDesk（クリニック向けAI業務代行）の事業仮説検証のためのインタビュー設計。
> **採用に限らず、クリニックの非診療業務全体でのBPO/AI活用ニーズを検証する。**
> 対象者は マイナビ（人材紹介）× 一宮西病院（801床・経営企画責任者）× 医療DX推進 の3視点を持つ希少人材。

---

## 0. v0.1 からの変更点

v0.1 は採用業務に特化していたが、本来 SuguDesk の事業仮説は **「AI BPO でクリニックのARPAを上げる」** であり、採用はその一候補に過ぎない。本版では：
- **非診療業務全体のペインマップ**を最初に取る（採用・集患・経理・レセプト・電話対応・労務・ナレッジ・経営管理）
- **どの業務が最もペインで、最も払うか**を見極める（ARPA拡大の順序判断）
- 採用は「深掘り対象の一つ」として後半に配置

---

## 1. インタビューの目的

クリニックの非診療業務全体において、BPO/AI代行のニーズと支払意欲を検証する。

検証したい3つの問い：
1. **クリニックの非診療業務で、最もペインが大きく・最もお金を払う業務はどれか？**（採用 / 集患 / 経理 / レセプト / 電話対応 / 労務 / ナレッジ / 経営管理）
2. **AI BPO（人＋AIの業務代行）に、どの業務でいくら払うか？意思決定・予算構造は？**
3. **AI/RPA/タスクシフトは、どの業務でどこまで現実的か？**

→ 結果として「**ARPA拡大の最初の一手はどの業務か**」「採用は本当に最初に攻めるべきか」を見極める。

## 2. この方から特に引き出すべき価値

| 経歴 | 引き出せること |
| --- | --- |
| **一宮西病院 経営企画責任者** | 医療機関の非診療業務の全体像、どこに人と金がかかるか、DXの優先順位、ROIの見方 ← **本インタビューの主役** |
| **医療DX推進（RPA/AI/タスクシフト）** | どの業務が自動化しやすく/しにくいか、現場の抵抗、タスクシフトの実例 |

⚠️ **注意**：現職は801床の大病院。**大病院とクリニックは体制が全く違う**（病院は専任部署、クリニックは事務長兼任・院長丸抱え）。「クリニックだとどうか」を都度確認。マイナビ時代のクリニック取引経験を引き出すのが鍵。

## 3. インタビュー設計（75分想定）

### イントロ・ラポール（5分）
- 自己紹介、SuguDeskの概要を1分で（採用に限定せず「クリニックの非診療業務をAIで代行する構想」と広く伝える）
- 「今日は答え合わせではなく、クリニック経営の実態を教えていただきたい」
- 「マイナビ時代はクリニックも担当されましたか？現職は大病院ですが、クリニックの内情もご存知ですか？」

### Part 1：非診療業務の全体ペインマップ（15分）
**目的：どの業務が一番のペインか、外注したいかを棚卸し。ARPA拡大の最初の一手を探る**

1. クリニックの院長・事務長が、診療以外で抱えている業務を棚卸しすると、どんなものがありますか？
2. その中で「一番時間を取られている」「一番ストレスが大きい」のはどれですか？
3. 「これは外注したい」「自分でやりたくない」と院長が思う業務トップ3は？
4. 逆に「外注したくない・自分でやるべき」と感じる業務は？
5. 経営企画の視点で、クリニックの非診療業務のうち「最もコスト（人件費・時間）がかかっている」のはどこですか？

※ 業務リスト（提示用）：採用 / 集患・マーケティング / 経理・請求・経費精算 / レセプト・医療事務 / 電話・予約・問い合わせ対応 / 労務・シフト管理 / 院内ナレッジ・教育・マニュアル / 経営管理・数値管理

### Part 2：業務別のBPO/支払意欲（20分）
**目的：各業務の「外注の現状」「ペインの大きさ」「払える金額」を横断的に**

業務ごとに以下を聞く（時間配分しながら主要3-4業務を深掘り）：
- 現状どう対応しているか（院長/スタッフ/外注）
- ペインの大きさ（5段階）
- すでに外注しているか、いくら払っているか
- AI＋人で代行されるなら、いくらまで払うか

6. **採用**：今どう採用していますか？紹介会社・媒体にいくら払っていますか？採用代行があれば使いますか？
7. **集患・マーケ**：LINE・口コミ・広告運用は誰がやっていますか？代理店にいくら払っていますか？
8. **経理・請求・経費**：会計・請求書処理は誰が？税理士以外の事務作業の負担は？
9. **レセプト・医療事務**：レセプト業務の外注ニーズは？派遣・委託の相場は？（規制も含めて）
10. **電話・予約対応**：電話の一次対応・予約変更の負担は？外注したいですか？
11. **労務・シフト・ナレッジ**：シフト管理、新人教育、マニュアル整備の負担は？
12. この中で「月¥80,000払ってでも外注したい」と院長が思う業務はどれだと思いますか？

### Part 3：意思決定・予算・価格（15分）
**目的：誰が・どの予算で・どう意思決定するか、¥80kの妥当性、ARPA拡大の可否**

13. クリニックの非診療業務の外注は、誰が意思決定しますか？院長単独？事務長？配偶者？
14. それぞれの業務の予算は、どの費目から出ますか？（人材費 / 販促費 / 外注費 / 顧問料）
15. 「複数の業務をまとめて1社に外注する」という発想は、クリニックに受け入れられますか？
16. 月¥80,000から始めて、業務を増やすごとに月額を上げていく（ARPA拡大）モデルは現実的ですか？
17. クリニックが「ツール（SaaS）を買う」のと「業務を人＋AIで代行してもらう」のと、どちらに金を払いやすい？
18. 経営企画視点で、こうした外注のROIはどう評価しますか？クリニック院長も同じ見方をする？

### Part 4：ベンダー選定・営業の入り方（GTM検証）（15分）
**目的：医療機関の購買プロセスと、スタートアップが入り込む方法。営業難易度の把握**
**※この方は 元ベンダー（マイナビ＝売る側）× 現バイヤー（病院経営企画＝買う側）の両面を知る最高の対象**

19. 病院・クリニックは、新しいサービスやベンダーをどう情報収集していますか？（紹介 / Web / 展示会 / 業界誌 / MR / 同業の口コミ など）
20. 経営企画として、ベンダーからの提案をどう評価・選定しますか？特に重視する点は？
21. 新規スタートアップからの提案は、受け入れられやすいですか？それとも警戒されますか？（実績の少なさ、事業継続性の不安など）
22. スタートアップが「まず話を聞いてもらう」ために有効なアプローチは何ですか？（紹介 / 無料トライアル / 同業の導入事例 / 医師の推薦 など）
23. 病院とクリニックで、営業の入り方・難易度はどう違いますか？クリニックの方が入りやすい？
24. 医療機関に「信頼される」ために必要な要素は何ですか？（導入実績 / 医師会・学会 / メディア露出 / 紹介ネットワーク など）

### Part 5：AI/RPA/タスクシフトの現実性（10分）
**目的：自動化の天井、現場の受容性、データ取得の現実性**

25. 医療DXでRPA/AIを推進された経験から、クリニックの非診療業務のどこが自動化しやすく、どこが難しいですか？
26. クリニックの現場（事務長・受付）は、新しいツールやチャットUIを使いこなせると思いますか？
27. AIが書類作成・データ集計・文面生成をやることに、現場の抵抗はありそうですか？
28. 各種データ（応募・会計・予約等）をメール転送やCSVで集約する方法、現実的に回ると思いますか？
29. 医療業界特有の規制・コンプラ上、業務代行で気をつけるべき落とし穴はありますか？（特にレセプト・個人情報）

### Part 6：採用・人材領域の深掘り（10分）
**目的：マイナビ経験から採用領域を深掘り（現プロトタイプの検証）**

30. 紹介会社のビジネスとして、クリニックは「おいしい顧客」でしたか？紹介手数料への反応は？
31. なぜ求人媒体・紹介会社は外部データ連携（API）を出さないのだと思いますか？
32. 採用した人が早期に辞める根本原因は？「辞めない採用」は求人票や事前コミュニケーションで改善できますか？
33. 「辞めない仕組みを作る」提案に、クリニック院長は価値を感じてお金を払うと思いますか？
34. SuguDeskのような業務代行が紹介会社と"組む"としたら、どんな形があり得ますか？

### Part 7：SuguDeskへの率直な評価（5分）
**目的：第三者の総合評価、見落としの発見、ARPA拡大の順序**

35. ここまで聞いた上で、SuguDeskの「一番の勝ち筋」と「一番のリスク」は？
36. **どの業務から始めるべきだと思いますか？（採用 / 集患 / 事務 / その他）その順序の理由は？**
37. 最初に攻めるべきクリニックのセグメント（業種・規模・地域）について、どう思いますか？
38. 率直に「ここが弱い」と思う点があれば教えてください。

## 5. インタビュー運用のコツ

- **誘導しない**：「○○だと思うんですが」ではなく「実際どうでしたか？」とオープンに
- **採用に寄せすぎない**：Part 1-2 で業務全体を広く取る。採用は Part 5 まで温存
- **クリニック限定で確認**：大病院の話に流れたら「クリニックだとどうですか？」と戻す
- **具体例と数字を引き出す**：「実際にあった事例」「だいたい何%」「月いくらくらい」
- **沈黙を恐れない**：相手が考える時間を待つ
- **最後に紹介依頼**：「同じ話を聞ける方を紹介いただけますか？」

## 6. アドバイザー化の可能性

この方は **月10時間まで稼働可・2026年5月開始希望**。インタビュー1回で終えず、**業務委託アドバイザー / 営業同行 / 紹介会社との橋渡し** として継続関係を作れる可能性大。

- 経営企画視点 → 事業計画・ARPA設計・資金調達の壁打ち
- マイナビ時代のクリニック人脈 → 営業リード
- 紹介会社の内側を知る → 連携交渉の設計
- 医療DX経験 → プロダクトの実現性レビュー

インタビューの最後に「継続的に壁打ち相手になっていただけますか？」と打診する価値あり。
