# 医療系採用サイトの「型」設計書

クリニック〜中小医療法人向けの採用サイトテンプレート。参考型のピックアップ → 推奨構成（サイトマップ） → ワイヤーフレーム → 根拠、の順にまとめる。ワイヤーの視覚版は同ディレクトリの `wireframe.html` を参照。

---

## 0. 前提の整理

| 項目 | 想定 |
|---|---|
| 発注者 | クリニック・中小医療法人（採用担当は院長 or 事務長が兼務） |
| ターゲット | 看護師（中途・パート中心）、医療事務、歯科衛生士など。新卒はオプション |
| デバイス | スマホファースト（医療職の求職行動はスマホ中心。夜勤明け・通勤中の閲覧を想定） |
| 運用体制 | 更新リソースが乏しい → **TOP 1ページに情報を集約し、下層は最小限**にする |
| ゴール | 応募（フォーム / LINE）。中間ゴールとして**見学・カジュアル面談** |

---

## 1. 参考になる「型」のピックアップ（3類型）

病院・クリニック採用サイトのデザイン集（後述の参考記事）を横断すると、成功パターンは概ね次の3類型に整理できる。

### 型A：看護部特設型（大病院に多い）
- 例としてよく挙げられるのは大学病院・大規模総合病院の看護部採用特設サイト（聖路加国際病院、亀田メディカルセンターの看護部サイトなど）
- **特徴**: コンセプトコピーを強く打ち出したブランディング型。教育制度・ラダー・キャリアパスのコンテンツが厚い。新卒向け説明会・インターン導線あり
- **向く相手**: 新卒を毎年まとまった人数採る病院
- **クリニックにそのまま使えない理由**: コンテンツ制作量・更新頻度が現実的でない

### 型B：クリニック親しみ型
- **特徴**: スタッフの実写写真＋院長メッセージ＋「1日の流れ」が中心。トーンは白基調＋暖色 or 医療系グリーンで清潔感と温かみを両立。ページ数が少なく1カラム縦長
- **向く相手**: 中途・パート採用が中心の診療所・歯科・小規模法人
- **強み**: 「どんな人と働くか」「人間関係」という医療職の最大の転職不安に直接答えられる

### 型C：データ・コンテンツリッチ型
- **特徴**: 「数字で見る◯◯病院」（平均年齢・有休消化率・残業時間・産育休復帰率）、職員座談会、FAQが充実。比較検討フェーズの中途求職者に強い
- **向く相手**: 競合が多い都市部、離職理由（残業・休暇）を定量で払拭したい医療機関

### → 推奨する「型」
**型Bをベースに、型Cの「数字で見る」「FAQ」を1セクションずつ移植したハイブリッド**。
理由: クリニックの応募者は中途が中心で、意思決定要因は「人間関係・休日・実際の働き方」。ブランディング（型A）より不安解消（B+C）が効く。制作・運用コストも1ページ完結型なら現実的。

## 2. 推奨サイト構成（サイトマップ）

```
TOP（1ページ集約・縦長LP型）
├─ 募集要項 /recruit/{職種}     … 職種別詳細（職安法の明示事項をここで担保）
├─ スタッフインタビュー /voice   … TOPには2〜3名の抜粋、下層に全文
└─ 応募・見学フォーム /entry    … フォーム＋LINE応募の2択
```

下層を3つに絞る理由: クリニックには更新担当がいない。「採用ブログ」「研修レポート」等の更新前提コンテンツは、止まった瞬間に逆効果（=活気がない印象）になるため型に含めない。

## 3. TOPページの構成とワイヤー（セクション順に根拠つき）

| # | セクション | 内容 | 根拠 |
|---|---|---|---|
| 1 | ファーストビュー | 職場の実写（スタッフの働く姿）＋コンセプトコピー＋職種チップ（募集中の職種）＋CTA2種（応募/まず見学） | 求職者の重視項目は「勤務地・休日」→ FVに勤務地とアクセスを明記。写真は素材集NG（実写が信頼の担保） |
| 2 | 数字で見る | スタッフ数 / 平均年齢 / 有休消化率 / 月平均残業 / 子育て中スタッフ数 の5枚タイル | 型Cから移植。離職理由の定量的払拭。数字は嘘がつけないため信頼性が高い |
| 3 | 院長メッセージ・理念 | 顔写真＋「どんな職場にしたいか」 | 小規模医療機関では「院長がどんな人か」が応募判断の最大変数 |
| 4 | 仕事内容・1日の流れ | タイムライン形式（8:30出勤 → … → 18:00退勤） | 入職後ギャップの防止。「残業がないこと」を時刻で示せる |
| 5 | スタッフの声 | インタビュー2〜3名（入職理由 / 前職との違い / 職場の雰囲気） | 看護学生・看護師の就活で最も見られるコンテンツが「先輩の声」。下層 /voice へ誘導 |
| 6 | 教育・働き方支援 | 未経験/ブランク可、研修、時短、急なお休み対応 | 教育制度は施設選びの主要チェック項目。クリニックでは「ブランク復帰」訴求が特に効く |
| 7 | 募集要項（抜粋） | 職種タブ切替＋主要条件のみの表 → 詳細は下層へ | 職安法の労働条件明示（後述チェックリスト）。「休日・給与」を探させない |
| 8 | FAQ | 人間関係 / 残業 / 子育て両立 / ブランク / 見学だけでも可？ | 応募直前の不安の最終処理。問い合わせ削減 |
| 9 | 見学CTA帯 | 「まずは30分、見学だけでも」 | 応募より心理ハードルの低い中間CV。見学希望は求職行動として定着している |
| 10 | 応募フォーム | 入力5項目以内＋LINEで応募ボタン | スマホでの離脱防止。医療職の連絡手段としてLINEが浸透 |

### 下層1：募集要項 /recruit/{職種}

職安法ベースの明示項目をテンプレート化（これが「型」の実務的な価値）:

- 業務内容 ＋ **変更の範囲**（2024/4改正で追加）
- 就業場所 ＋ **変更の範囲**（同上）
- 契約期間（有期の場合は**更新上限の有無・内容**）（同上）
- 試用期間の有無・期間・条件差
- 賃金（基本給・手当・固定残業の内訳）
- 労働時間・休憩・休日・時間外の有無
- 社会保険の適用
- 受動喫煙防止措置
- 募集者の氏名または名称

### 下層2：スタッフインタビュー /voice
写真大きめ1カラム。質問は全員共通（入職理由 / 仕事のやりがい / 職場の雰囲気 / 応募者へ一言）にして取材・制作を型化する。

### 下層3：応募フォーム /entry
- 必須項目は 名前 / 電話 or メール / 希望職種 / 希望連絡時間帯 の4つまで。履歴書添付は求めない（面接時でよい）
- 「LINEで応募・相談」を並列配置
- 送信後サンクスページで「◯営業日以内にご連絡します」と明示

## 4. 根拠まとめ（リサーチソース）

1. **求職者の重視項目は「勤務地」「休日・休暇」**（看護学生就職活動意識調査・メディカルサポネット等）→ FVと募集要項抜粋で先出しする構成にした
2. **「先輩の声」「教育制度」が採用サイトで最も見られるコンテンツ群**（看護roo!就活・ナース専科就職などの就活サイトの主要コンテンツ構成からも裏付け）→ セクション5・6を必須化
3. **職業安定法：募集時の労働条件明示は義務**。2024年4月改正で「業務の変更範囲」「就業場所の変更範囲」「有期契約の更新上限」の明示が追加（厚労省）→ 募集要項テンプレートに反映
4. **採用サイトは医療広告ガイドラインの対象外**（患者への誘引性がないため）→ 患者向けHPより表現の自由度が高く、スタッフ写真・待遇訴求を前面に出せる。ただし患者向けページと兼用する場合は対象になり得るため採用サイトは分離する
5. **見学・説明会は求職行動として定着**（看護学生の病院見学・説明会参加率の高さ）→ 応募より軽い中間CV「見学」を独立CTAとして設計
