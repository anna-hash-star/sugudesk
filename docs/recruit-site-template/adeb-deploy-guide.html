採用サイトを adeb.com/recruit に公開する方法

新しい採用サイトを、御院のドメイン内（https://www.adeb.com/recruit/）で公開するための進め方をまとめました。WordPressはそのまま運用を続けながら、同じURLの中身を新しい採用サイトに置き換えます。

1実現したいこと

いまある adeb.com/recruit/ を、新しい採用サイトに置き換えます。
URL（住所）はそのまま。中身だけを新しくします。御院のドメイン内に置くので、これまでadeb.comが積み上げてきた検索評価（SEO）を活かせます。

2公開のしくみ（かんたんに）

新しい採用サイトを、adeb.com のサーバー側で /recruit に割り当てます。方法は2通り（サーバー環境に合わせて選びます）：①当方のサイトに転送する（リバースプロキシ）、または ②表示用ファイル一式を /recruit に置く。いずれも WordPress本体には触れません（このサイトはNginxなので、①の転送方式とも相性が良いです）。

💡 「WordPressの中に直接入れられないの？」について：新しい採用サイトは、WordPressとは別の技術で作られています（動く仕組みが違います）。そのため、WordPressの記事・固定ページとして"貼り付ける"ことはできません。その代わりに、同じサーバー・同じドメインに"並べて置く"ことで、adeb.com/recruit として一体に見せます。表示側・SEO側の見え方は、同じドメイン内で完結します。

3作業の流れ（役割分担）

制作側 当方

  1. 採用サイトを、adeb.com/recruit に置けるファイル一式に書き出し
  2. そのファイル一式と、設置手順書（下記④〜のやり方）をお渡し

サーバ側 御院（Web担当者様）

  1. いまの /recruit の固定ページを退避（差し替え可なら非公開に）
  2. サーバー設定（Nginx）で /recruit を別扱いに ＝「当方サイトに転送」または「静的ファイルを表示」
  3. （静的ファイル方式の場合）お渡しするファイル一式を /recruit へアップロード
  4. https://www.adeb.com/recruit/ を開いて表示確認

※このサイトのサーバーは Nginx です。/recruit をWordPressと別扱いにする設定は、サーバー設定（Nginx）を触れる方＝Web担当者様／現在のサイト制作会社様の作業になります（WordPressの管理画面だけでは完結しません）。手順書はお渡しします。

4事前に教えていただきたいこと

この3点が分かると、最適な方法を確定できます

  • いまの adeb.com/recruit/ の固定ページは何に使っていますか？（差し替えてよいか）
  • サーバー設定（Nginx）を触れるのはどなたですか？（自社／制作会社）— adeb.com/recruit 実現の鍵です
  • ホスティング会社はどこですか？／FTP等でファイルを置けますか？（静的ファイル方式を採る場合に必要）

5この方式のメリット

  • URLは adeb.com/recruit のまま ＝ SEOはadeb.com本体の評価に乗る
  • WordPressはそのまま運用継続（作り替え不要）
  • 応募フォーム（formrun）・採用チャットもそのまま動きます
  • 追加のサーバー契約・月額費用は不要
