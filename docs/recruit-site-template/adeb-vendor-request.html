作業依頼書 / WORK REQUEST — AdeB CLINIC 採用サイト

採用サイト（新版）を https://www.adeb.com/recruit/ に設置いただく作業のご依頼

現在 /recruit にある採用ページ（Elementor固定ページ）を、新しい採用サイト（静的サイト一式）に差し替えたく存じます。URLは変更せず（SEO資産を維持）、対象は /recruit/ のみです。WordPress本体には影響しません。作業目安：15〜30分程度の想定です。

1背景・ゴール

  • 現状の /recruit は旧版のため、新デザインの採用サイトに置き換えたい。
  • URL /recruit はそのまま維持（これまでのSEO評価を引き継ぐため）。
  • 採用サイトは静的ファイル（HTML/CSS/JS）一式としてお渡しします（サーバー側でPHPやDBは不要）。

2ご依頼内容（サマリ）

下記3点だけです。詳細は「4. 作業手順」に記載します。

  • ① お渡しするファイル一式をサーバーに配置
  • ② nginx に /recruit/ 用の location ブロックを1つ追加
  • ③ nginx を reload して表示確認

3当方からのお渡し物

提供物内容
採用サイト一式（zip）静的ファイル。/recruit 配下で自己完結するよう構成済み（アセットも /recruit/… を参照）
nginx 設定サンプル本書「4-②」の内容。実ファイルに合わせて最終確認済みのものをお渡し
本依頼書 / 手順書この資料

4作業手順

  1. ファイルを配置
    お渡しするファイル一式を、サーバー上の任意の場所に展開してください。
    例：/var/www/adeb/recruit/（実際のドキュメントルート構成に合わせてください）
  2. nginx に location を追加（対象サーバーブロックへ） 
    # /recruit（末尾スラッシュ無し）→ 付きへ寄せる
location = /recruit { return 301 /recruit/; }

# /recruit/ 配下は静的ファイルを返す（WordPressに渡さない）
location ^~ /recruit/ {
    alias /var/www/adeb/recruit/;   # ①で配置した場所
    try_files $uri $uri.html $uri/ /recruit/index.html;
}
    ※ alias のパスは①の配置先に合わせてください。既存の location / { … index.php … } より上（または ^~ による優先）で効きます。
  3. 設定を反映 
    nginx -t && systemctl reload nginx
  4. 表示確認
    https://www.adeb.com/recruit/ と、配下ページ（例 /recruit/jobs/…）が表示されることをご確認ください。
  5. （WP側）旧・採用固定ページを非公開に
    既存の recruit スラッグの固定ページは非公開／下書きにしてください（URL衝突・重複回避のため。実表示はnginxが静的側を優先します）。こちらはWP管理画面での操作です。

WordPress本体には影響しません

上記の設定は /recruit/ だけを対象にした隔離ブロックです。トップページ・施術メニュー等、他のURLはこれまで通りWordPress（PHP）が処理します。静的ファイルを返すだけなので、サーバー／PHPのバージョンにも依存しません。

5更新時の運用

文言・写真・求人内容を更新する際は、当方が新しいファイル一式をお渡ししますので、①と同じ場所に上書きアップロードしていただくだけです（nginxの再設定は不要）。

6事前に教えていただきたいこと

  • ファイルの配置先パス（例：ドキュメントルートの位置）と、アップロード方法（SFTP/SSH 等）
  • 編集するnginx設定ファイルの場所（例：/etc/nginx/conf.d/adeb.conf 等）
  • この方式で問題がないか（別案としてリバースプロキシも可能です。ご希望あればご相談ください）

7確認チェックリスト

  • nginx に /recruit/ の location を追加した
  • nginx -t がOK、reload 実施
  • /recruit/ と配下ページの表示を確認
  • 旧・採用固定ページを非公開にした
