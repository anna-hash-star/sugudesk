医療系採用サイトの型
構成・ワイヤーフレーム設計書

クリニック〜中小医療法人向け。参考3類型の分析から「1ページ集約＋下層3枚」の型を定義する。緑色の要素はすべて応募導線（CTA）。

01参考にする型 — 3類型

病院・クリニック採用サイトの事例集を横断すると、成功パターンは3類型に整理できる。

TYPE A

看護部特設型

大病院の看護部採用サイトに多い。コンセプトコピー先行のブランディング型で、教育制度・クリニカルラダーのコンテンツが厚い。

向く相手
新卒を毎年まとめて採る病院
難点
制作量・更新頻度がクリニックには過大
TYPE B

クリニック親しみ型

スタッフ実写＋院長メッセージ＋「1日の流れ」が中心。白基調に暖色 or 医療系グリーン。1カラム縦長で完結。

向く相手
中途・パート採用中心の診療所
強み
最大の転職不安「人間関係」に直接答える
TYPE C

データ・コンテンツリッチ型

「数字で見る」（平均年齢・有休消化率・残業）、座談会、FAQが充実。比較検討中の中途求職者に強い。

向く相手
競合の多い都市部の医療機関
強み
離職理由（残業・休暇）を定量で払拭
推奨：B をベースに C の「数字で見る」「FAQ」を移植したハイブリッド

クリニックの応募者は中途中心で、意思決定要因は「人間関係・休日・実際の働き方」。ブランディングより不安解消が効き、1ページ完結なら運用コストも現実的。

02サイト構成

更新担当がいない前提で下層は3枚に絞る。採用ブログ等の更新前提コンテンツは、止まった瞬間に「活気がない」印象になるため型に含めない。

TOP（縦長LP型・情報集約）
  • 募集要項（職種別）/recruit/{job}
  • スタッフインタビュー/voice
  • 応募・見学フォーム/entry

募集要項ページが職業安定法の労働条件明示（§05）を担保する。

  1. ファーストビュー求職者の最重視項目「勤務地・休日」をFVで即答。写真は必ず実写 — 素材写真は信頼を毀損する。

  3. 院長メッセージ小規模医療機関では「院長がどんな人か」が応募判断の最大変数。
  4. 1日の流れ入職後ギャップの防止。「残業がない」ことを時刻で示せる。
  5. スタッフの声看護職の就活で最も見られるコンテンツ。質問を全員共通にして制作を型化。
  6. 教育・働き方支援教育制度は施設選びの主要チェック項目。クリニックでは「ブランク復帰可」が特に効く。
  7. 募集要項（抜粋）職種タブで主要条件のみ。「休日・給与」を探させない。詳細は下層で法定明示を担保。
  8. FAQ応募直前の不安の最終処理。「見学だけでも可？」を必ず入れる。
  9. 見学CTA応募より心理ハードルの低い中間コンバージョン。見学・説明会は求職行動として定着している。
  10. フォーム必須4項目まで（名前・連絡先・職種・連絡時間帯）。履歴書添付は求めない。LINE応募を並列。

05法令チェックリスト（募集要項テンプレに内蔵）

職業安定法により募集時の労働条件明示は義務。2024年4月改正の追加3項目（緑字）を漏らさない。なお採用サイト自体は患者への誘引性がないため医療広告ガイドラインの対象外 — ただし患者向けHPと兼用すると対象になり得るため分離する。

  • 業務内容 ＋ 変更の範囲（2024/4追加）
  • 就業場所 ＋ 変更の範囲（2024/4追加）
  • 契約期間／有期の場合は 更新上限の有無・内容（2024/4追加）
  • 試用期間の有無・期間・その間の条件差
  • 賃金（基本給・手当・固定残業代の内訳）
  • 労働時間・休憩・休日・時間外労働の有無
  • 社会保険・労働保険の適用
  • 受動喫煙防止措置の状況
  • 募集者の氏名または名称
