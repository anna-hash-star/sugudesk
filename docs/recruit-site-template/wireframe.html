参考4サイト分析＋チャット採用相談

クライアント指定の実在4サイト（クリニック2・グループ1・病院1）の構造分析をベースに再構成。自社の強みであるチャットを「採用相談」導線として型に標準装備する。緑＝応募導線、緑枠淡色＝チャット導線。

v2の変更点: TOP1枚LP型 → TOP＋職種別ページのハブ型へ／CVを「チャット相談→見学→応募」の3段に再設計

01参考4サイトの構造分析

検索エンジンにインデックスされた下層URL群から各サイトの情報設計を再構成した（ページ内のセクション順は推定を含む）。

REF 1 — グループ採用ポータル型

自由が丘クリニックグループ

jc-recruit.jp

美容医療・化粧品グループ。知る(about) → 仕事(work/welfare) → 人(interview) → 条件(recruitment) の4層ファネル。要項は職種×拠点でURL分割（nurse_meguro 等）。

取り入れる点福利厚生の独立コンテンツ化／職種別インタビュー／職種単位URL（媒体・検索からの直接着地に強い）
REF 2 — 単院・職種ハブ型

りつの内視鏡クリニック

ritsuno-recruit.com

「スタッフ自身が幸せになる」を掲げる内視鏡専門クリニック。/data/（数字でわかる）、職種ごとの紹介ページ（/nurse/ /doctor/…）＋要項ページ、/tour/（施設見学の流れ）。

取り入れる点数字でわかる／見学を「流れ」として見せる／理念を働く人に向ける
REF 3 — 採用専用ミニマル型

梶ヶ谷クリニック

kajigaya-clinic.com/recruit/

患者向けサイトから採用専用サイトを分離。/clinic/（医院紹介）/voice/（スタッフの声）＋職種×雇用形態別の要項。有休消化100%目標・トレーナー制＋チェックリスト3ヶ月を明文化。

取り入れる点採用サイト分離／要項を常勤・パートで分割／教育を「制度名＋期間」で具体に
REF 4 — 病院・多職種ポータル型

けいゆう病院

keiyu-hospital.com/recruit/

職種大分類（/nurses/）の中に教育体制・病院説明会・募集要項を入れ子で持つ2階層構造。要項は部署・雇用区分別（ward / ope / nurse-new…）。/entry/ で問合せとエントリーを統合。

取り入れる点病院規模は大分類→詳細の2階層／説明会・見学会の常設イベント化
4サイトの共通項（型に昇格させる要素）
  • 職種別ページが構造の中心 — 4サイト全てが職種（×拠点 or ×雇用形態）単位でURLを分割。求職者は自分の職種しか読まない
  • 見学・説明会が独立した中間CV（REF 2・3・4）
  • スタッフの声／インタビューは全サイト標準装備
  • 数字・具体の訴求（/data/、有休100%、トレーナー制3ヶ月）
  • 問合せ手段は電話・メール・フォームのみ — チャット相談はどのサイトにも無い ＝ SuguDeskの差別化ポイント

03サイト構成 v2

TOP1枚集約（v1）から「TOP＋職種別ページ」のハブ構造へ。REF 2式の「職種紹介と要項の分離」は運用リソースを考え統合し、職種ページ1枚に働き方＋要項をまとめる。

TOP（ハブ）
  • 職種別ページ/jobs/{nurse|clerk|…}仕事内容＋1日の流れ＋先輩の声＋要項
  • スタッフの声/voice
  • 見学・応募の流れ/flow
  • エントリー/entry
  • ◎ チャットで採用相談全ページ常駐ウィジェット

医院紹介・数字で見る・教育はTOPに集約（下層化は更新が回る場合のみ）。病院規模は /jobs/ を「看護部門・医療技術部門・事務部門」の大分類2階層に拡張（REF 4式）。

05チャット「採用相談」の設計

FAQ・募集要項と同一ナレッジを参照（SuguDeskの回答ルール資産を流用）。募集条件に触れる応答は労働条件明示（§07）と矛盾しないよう要項と同期させる。

07法令チェックリスト（募集要項テンプレに内蔵）

職業安定法により募集時の労働条件明示は義務。2024年4月改正の追加3項目（緑字）を漏らさない。採用サイト自体は誘引性がなく医療広告ガイドライン対象外 — REF 3のように患者向けサイトと分離するのが安全。チャットの応答も募集条件に触れる場合は要項と同期させる。

  • 業務内容 ＋ 変更の範囲（2024/4追加）
  • 就業場所 ＋ 変更の範囲（2024/4追加）
  • 契約期間／有期の場合は 更新上限の有無・内容（2024/4追加）
  • 試用期間の有無・期間・その間の条件差
  • 賃金（基本給・手当・固定残業代の内訳）
  • 労働時間・休憩・休日・時間外労働の有無
  • 社会保険・労働保険の適用
  • 受動喫煙防止措置の状況
  • 募集者の氏名または名称
