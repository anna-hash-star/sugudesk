## 0. エグゼクティブ・サマリー

**SuguDeskの販売代理提携について、両社のwin-winが成立する経済条件と段階的ロードマップをご提案します。**

- **提携スコープ**：ライトプランを中心とした販売代理。ギミック様のクリニックネットワーク（ドクターズ・ファイル等）経由の共同営業。
- **経済条件の骨子**：月額売上の50%をギミック様にお渡しする形を基本とし、初期費用はプラン・条件によって調整。
- **ロードマップ**：6月のPhase 1完了を起点に、**神奈川パイロット → 関東圏拡大 → 全国展開**の3段階で展開。
- **両社のメリット**：
  - ギミック様：既存クリニック顧客のARPU向上、粘着性強化、Dr's Fileの差別化。
  - exmore：ギミック様の全国クリニックネットワークへの接続、共同営業による効率的な開拓。

## 4. 経済条件（本提案の中核）

### 4.1 基本設計

**月額売上の50%をギミック様にお支払い（販売手数料）**

- exmore → 契約・請求はexmore名義、売上はexmore口座へ

- 契約期間12ヶ月（pricing.md準拠、クリニック様向けの標準条件）

### 4.2 初期費用の扱い（プラン別）

| プラン | 初期費用の扱い |
|--------|----------------|
| **ライト** | **クリニック様に全額ご負担いただく**（弊社取り分100%） |
| スタンダード | クリニック様に全額ご負担いただく（弊社取り分100%） |
| プレミアム | クリニック様に全額ご負担いただく（弊社取り分100%） |

**初期費用は月額シェア対象外**とさせていただきたく、以下の理由からご理解をお願いします：

1. FAQ構築・Widget設定・プロンプト調整等の**実作業工数が発生**します（ライトで約5時間、プレミアムで約20時間）
2. 初期費用は**構築原価の回収**であり、販売代理の対象ではなく**実装サービス**の対価です
3. 初期費用をシェア対象とすると、弊社はクリニック1社あたり赤字スタートとなり、**提携の持続可能性が失われます**

## 5. 段階的ロードマップ（3 Stage）

**考え方**：両社にとってのリスクを最小化するため、小さく始めて成果が出たら広げる。

### Stage 1：神奈川パイロット（6月〜9月、4ヶ月間）

- **対象エリア**：神奈川県限定（5〜10院）
- **プラン**：ライトプランを中心に
- **目的**：
  - 共同営業のオペレーション検証
  - 実際のチャーン率・クリニック満足度の実測
  - FAQ構築・運用のセルフサービス化品質の確認
  - ギミック様の営業レポート・精算フローの構築
- **経済条件**：月50%シェア、ライト初期費用はクリニック負担
- **マイルストーン**：
  - 6月：1〜2院オンボード
  - 7月：3〜5院累計
  - 9月末：5〜10院累計、稼働率・チャーンの初期データ取得

### Stage 2：関東圏拡大（10月〜3月、6ヶ月間）

- **対象エリア**：東京・埼玉・千葉を追加（累計30〜50院）
- **プラン**：ライト中心、希望クリニックにスタンダード／プレミアムも提案
- **目的**：
  - スケール検証
  - ギミック様のオペレーション本格活用
  - exmoreの運用体制拡充
- **経済条件**：Stage 1と同条件（月50%、ライト初期クリニック負担）
- **マイルストーン**：
  - 10-12月：月5院ペースでオンボード
  - 1-3月：月10院ペースに加速
  - 3月末：累計30〜50院

### Stage 3：全国展開（Phase 2完了後、2027年Q4想定）

- **対象エリア**：全国
- **プラン**：フルラインナップ（F2-3 HPクロール自動FAQ生成も活用）
- **目的**：
  - 100院規模への到達
  - 継続的なBPOアップセル（SuguDeskから事務長代行・採用支援へ）
- **経済条件**：Stage 1/2の成果に応じて両社で再協議

## 6. 実務オペレーション

### 6.1 営業プロセス

1. **リード発生**：ギミック様のネットワークから紹介
2. **初回商談**：両社営業担当が同席
3. **提案**：ライトプランを基本、ニーズに応じてスタンダード／プレミアム提案
4. **契約**：exmore名義で締結

### 6.2 売上・精算フロー

1. **請求**：exmore → クリニック様（月末締め）
2. **入金**：クリニック → exmore口座
3. **シェア支払い**：exmore → ギミック様（月額売上の50%）
4. **精算レポート**：月次で紹介件数・稼働状況・シェア額をギミック様に共有

### 6.3 サポート窓口

- **一次窓口**：exmoreのCSチーム
- **二次エスカレーション**：ギミック様経由の要望はexmoreで対応、ギミック様と定期共有
- **定例会**：月次で両社営業・運用ミーティング

### 6.4 データ連携（Phase 2以降検討）

将来的に以下のシステム連携を検討：
- 紹介クリニックのトラッキング（専用URL／クーポンコード）

## 8. 議論したい論点

### 8.1 初期費用の扱い

**弊社提案**：**クリニック様ご負担（ギミック様のシェア対象外）**

議論ポイント：
- ギミック様のご要望として「クリニックの初期負担をゼロにしたい」というスタンスがある場合の対応
- 弊社からは**「初期無償化」はStage 3（Phase 2完了後・運用成熟後）で再検討**をご提案
- Stage 1/2では弊社の構築原価回収のため、クリニック様負担をお願いしたい

### 8.2 月額シェア50%の妥当性

ご要望として承知しておりますが、**弊社の持続可能性**の観点から以下をご理解いただきたい：
- メンテ原価・LLM API・インフラコストを差し引くと、弊社月額粗利は約¥2,800/社（Phase 1後想定）
- 提携の長期継続のため、チャーン率が悪化した場合の条件見直しを条項に含めたい

### 8.3 独占／非独占の扱い

- ギミック様経由のクリニックをexmoreが他経由で受ける場合のルール
- ギミック様が競合サービス（他のAI受付等）を扱う場合のルール

### 8.4 契約期間と更新条件

- 提携契約の期間（1年／2年）と自動更新条件
- 各Stage終了時の成果評価と条件見直し

### 8.5 最終譲歩カードの提示

仮にギミック様が「ライト初期費用の半額負担まで」を強く求められた場合、**Stage 2以降で初期費用の折半（ギミック様¥75,000、exmore¥75,000）への移行を検討**する余地があります。ただし：
- 弊社の月次粗利が1年で¥100k下がる試算
- この譲歩はStage 2/3のシェア率調整とセットでの議論をお願いしたい
