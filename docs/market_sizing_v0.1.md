## 3. 離職率・ミスマッチの実態

### 一次データ（離職率）

| 指標 | 数値 | 出典 |
|---|---|---|
| 看護師正規雇用 離職率 | **11.3%** | 日本看護協会 2024年病院看護実態調査 |
| 同 既卒採用 1年未満離職率 | **16.1%** | 同上 |
| クリニック既卒採用者 1年未満離職率 | **約32%**（3人に1人） | CLIUS 個人運営事業所調査 |
| 医療・福祉 大卒3年以内離職率 | 38.6% | 厚労省 |
| 医療・福祉 高卒3年以内離職率 | 46.2% | 厚労省 |
| 紹介経由看護師 6ヶ月以内離職率 | **23.1%**（他経路の約2倍） | 福祉医療機構 |

### 経済損失（1人あたり）

| 区分 | 損失額 | 出典 |
|---|---|---|
| 早期離職 新卒 | 657万円 | エン・ジャパン試算 |
| 早期離職 中途 | **774万円** | レバテック試算 |
| 3ヶ月以内離職（概算） | 187.5万円 | 同上 |

### 業界全体の損失規模

- クリニック10.5万院 × 平均スタッフ5名 × 離職率15% ≒ **年間約8万人がクリニックで離職**
- ミスマッチ起因（3-4割と仮定）= 約2.5〜3万人が早期離職
- 1人あたり200万円の損失換算で **年間約500〜600億円の経済損失**

### 紹介経由23%離職の損失だけで

- 紹介経由でクリニック入職 約5万人/年 × 23% = **約1.1万人の早期離職**
- 無駄になる紹介手数料だけで **約84億円/年**
- 再採用・機会損失を含めると **総額200億円超/年**

## 4. 「辞めない採用」訴求の根拠

事務長フィードバック「ミスマッチしているから辞める → ミスマッチしない採用を実現しませんか？」に対して、数字で正当化：

### コア訴求

> 「離職率の高い業界です。  
> 紹介経由の看護師は半年以内に**23%**が辞めます。  
> 100万円の紹介手数料のうち **23万円が消える計算**。  
>   
> 辞める原因はミスマッチ採用。  
> 求人票が実態を反映していない、事前コミュニケーションが足りない、面接で適性を見抜けない、入職後フォローがない。  
>   
> **SuguDeskは「辞めない仕組み」を作るサービス**です。  
> ・求人票の作り込み  
> ・応募者FAQと事前コミュニケーション  
> ・面接質問の標準化と振り返り  
> ・入職後6ヶ月の定着フォロー  
>   
> 月¥80,000で、御院の離職コストを当社が肩代わりします。」

### 院長/事務長が「辞めない仕組みのコスト」を払う合理性

```
1名離職するときの院長損失：
  紹介手数料     ¥76万
  再採用工数     ¥20万
  既存スタッフ疲弊
  患者対応の質低下
  ─────────────────
  最低でも       ¥100万/件
  
↓

SuguDesk 年額 ¥96万 で「辞めない仕組み」が手に入る
  → 年1件の早期離職防止で元が取れる
```

## 5. 営業ピッチに使える「衝撃の数字」5つ

1. **「紹介手数料1件76万円。SuguDesk年額96万円。年2名採用なら採用コスト半額」**

2. **「クリニックの既卒スタッフ、3人に1人が1年以内に辞めます」**（個人運営クリニック既卒1年未満離職率32%、CLIUS）

3. **「美容クリニックは3年で4割増、市場1.5倍。一方で看護師は最大27万人不足。採用は奪い合い」**（厚労省・東商）

4. **「ミスマッチ採用1人で平均774万円の損失。看護師1人辞めると確実に100万円超が消える」**（エン試算）

5. **「クリニック8万院は採用担当を専任で置けない採用難民。SuguDeskが事務長兼任の代わりに動きます」**
