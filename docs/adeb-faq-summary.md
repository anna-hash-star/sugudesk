# AdeBクリニック秋田院 ― チャット構築 突合作業 まとめ

JSON構造化ナレッジ（投入済み）と既存FAQ（投入済み・2,034行）を全件突合し、
**重点確認ポイントと具体的な修正方法**を確定したサマリです。

## 1. 対象データ
| 区分 | 内容 |
|---|---|
| JSONナレッジ | `docs/adeb-data.json`（AdeBクリニック秋田院。faqs 14 / treatment_menus 62 / price_items 337 / answer_rules 9 / unsupported 7 ほか） |
| 既存FAQ | `_AdeB…FAQ.xlsx` → **2,034行**（faq 1,379 / faq_campaign 22 / faq_interval 633、質問バリエーション約5,640） |
| 方針 | JSONを正。JSONで足りない所をFAQで補填。矛盾はJSON優先 |

## 2. 突合の全体像（結論）
両者は同一HP由来で**大半が整合**。新規Q&Aの追加は不要。問題は3カテゴリに集中し、
ガードレール（終了メニュー・粉瘤・ピアス・ボトックス用量・ミノキ・一般皮膚科）は概ね健全でした。

- 金額を含むFAQ **172件**をJSON価格マスタと自動照合 → 差分のみ抽出
- 確定した課題 **27件**（P1=16 / P2=7 / P3=4）→ `docs/adeb-faq-review/issues_final.csv`

## 3. 重点確認ポイントと修正方法

### 🔴 P1 即対応（16件）
| 課題 | 内容 | 修正方法 |
|---|---|---|
| 価格矛盾・HARG（2件） | 6回セットが **349,200** と **343,200** で混在 | `349,200円→343,200円`（90,200×6−198,000=343,200が正） |
| 価格矛盾・イボレーザー（3件） | **旧価格6,500系**が混在 | `6,500→7,000 / 13,000→13,500 / 19,500→19,800`（JSON・他FAQと一致） |
| 予約電話の出し分け（11件） | 予約案内に **5880**（本来 予約専用=5800） | 受付に正番号を確認し統一。`fix_list.csv`の11行を一括置換 |

### 🟠 P2 要対応（7件）
| 課題 | 内容 | 修正方法 |
|---|---|---|
| JSON価格欠落 | HARG / 薄毛プラン（メンズ・レディース）/ 粉瘤手術(保険) / **男性脱毛** がmasterに無い | FAQ値を正にmaster登録（薄毛は新プラン料金を確認） |
| 二重登録の一本化 | 「事前予約は必要ですか」JSONとFAQで表現相違 / 「支払い方法」に会員コースの別Q混在 | JSON優先で回答一本化、重複は非公開化 |
