### 1-2. 表面の微修正提案（ギミック配布版）

このまま使ってもOK。ただしギミック営業配布版として整えるなら以下を検討：

- 右上角に **「ギミック × ドクターズ・ファイル ご紹介特典」** リボン

- 価格の月額¥8,000〜の横に小さく **「初期費用 ¥150,000 → ¥100,000（紹介特典）」** を追記

> **注**：表面を大きく作り変えると印象が変わるので、上記は小さくのせる程度で十分。

## 2. 裏面（新規設計）

### 2-1. 裏面メインキャッチ（紙面上部）

**他のAIチャットでは伝わらない、"先生の人柄"まで届く理由。**

> サブコピー（小さめ）
> ホームページ ＋ ドクターズ・ファイル ＋ 先生のQ&A
> 3つの情報源を学習し、患者さまに事実と想いを届けます。

### 2-2. 仕組み図：3つの情報源（紙面の中段・主役）

```
┌─────────────┐    ┌──────────────────┐    ┌─────────────┐
│ クリニックHP  │    │ ドクターズ・ファイル│    │ 先生のQ&A    │
│              │    │                    │    │              │
│ 診療時間     │    │ 経歴・実績         │    │ よくある質問 │
│ 料金         │  ＋ │ 得意な治療         │ ＋  │ への院独自  │
│ アクセス     │    │ 開業の想い         │    │ の回答      │
│ 予約方法     │    │ 人柄・ストーリー   │    │              │
└──────┬───────┘    └─────────┬────────┘    └──────┬──────┘
       └─────────────────────┴────────────────────┘
                              ▼
                  ┌────────────────────────┐
                  │     SuguDesk AI         │
                  │ 事実 × 想い で回答する  │
                  └────────────────────────┘
                              ▼
                ✨ 患者さまに、安心と信頼が届く ✨
```

> 💡 **ポイント注釈**
> ドクターズ・ファイルに掲載されている先生の情報は、患者さまが来院前に最も知りたい
> 「この先生はどんな人か」を補う情報源として、AIチャットに大きな差を生みます。

### 2-3. 圧倒的な差：Before / After 比較表（裏面の顔）

| 患者さまからの質問 | 一般的なAIチャット | **SuguDesk × ドクターズ・ファイル** |
|---|---|---|
| 「紹介状なくても受診できますか？」 | 「受診可能です。」 | 「紹介状なしでもご受診いただけます。○○院長は『誰もが気軽に相談できる場でありたい』との想いで開業されており、初診の方も丁寧にお話を伺います。」 |
| 「ニキビ跡で悩んでて…」 | 「治療メニュー一覧はこちら→」 | 「○○院長は△△治療の症例実績が豊富で、肌質に合わせた治療を大切にされています。まずはお気軽にご相談ください。」 |
| 「子ども連れでも大丈夫？」 | 「キッズスペースあり。」 | 「お子さま連れも歓迎です。○○院長は『家族で通えるクリニック』を目指して開業されました。キッズスペースもございます。」 |
| **伝わるもの** | 事実だけ | **事実 ＋ 先生の想い・人柄** |
| **患者さまの心理** | 比較材料が増えただけ | **「ここに行きたい」と思える** |

1. 「先生のクリニック、深夜や休診時間にも問い合わせ来ますよね？受付スタッフさんも大変ですよね。」

3. 「ただ、AIチャット自体は他社さんもあるんです。**SuguDeskが他と違うのは、ここなんです。**」
4. （Before/After表を指差しながら）「他社は事実だけ答える。SuguDeskは、**ドクターズ・ファイルに載っている先生の歩みや想いまで踏まえて答える**。これは、ドクターズ・ファイル掲載クリニックさんだけの強みなんです。」
