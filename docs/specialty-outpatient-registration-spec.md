# 専門外来 登録仕様（お悩み・症状／診療メニュー）

各専門外来を「症状→科の振り分け＋予約案内」まで答えられるよう、エンティティに落とす仕様。統合ナレッジは横断インデックスとして併存可だが、拾う主役はお悩み・症状。

## 0. 登録の原則
1. **専門外来1つ＝お悩み・症状1件**（主役・キーワードで拾う）。
2. 検査・施術・料金・保険・予約要否があるもの＝**＋診療メニュー1件**。
3. **予約はL1応答ルール（短縮版）に集約**。各エンティティの「当院の治療方針」には予約文を1文だけ添える（M型／特殊型）。「予約が必要です」と単独で書かない（初診ルールと矛盾するため）。
4. リンクは**プレーンURL**（Markdown名前付きリンク禁止＝検証済）。公開トグルON。
5. 「受診時に医師が案内・予約します」等の**約束表現は入れない**。

## 1. お悩み・症状 標準フィールド
- 名称／別名・キーワード／一般説明／主な症状／当院の治療方針／関連診療科／関連メニュー／公開ON

### 治療方針テンプレ（M型・約束表現なし）
```
〔症状〕は〔科〕（〔専門外来〕）で対応しています。〔補足の事実〕。
まずは〔科〕の午前の一般外来（受付 月〜土 8:00〜12:00）を受診してください（予約不要）。
紹介状をお持ちの方は、地域連携室（0586-48-0022／月〜金 8:00〜17:00・土 8:00〜12:00）へご連絡ください。
詳しくはこちらをご確認ください。
[〔科〕のご案内ページ](〔科ページURL〕)
```
※リンクはチップ形式 `[表示名](URL)`（訂正済）。お悩みの締めは「まず午前来院（予約不要）」＋「紹介状ありは地域連携室」の2本。紹介状なしの再診予約（予約センター）はL1／予約ページに委譲。
### 治療方針テンプレ（特殊予約型）
- 甲状腺超音波外来：「甲状腺超音波外来は予約制です（月・火・水・金 14:00〜15:00、受付B棟2階O）。まずは内分泌・糖尿病内科の午前の一般外来を受診してください。」
- 腎臓内科（透析予防・腎代替療法選択・高血圧専門医・シャント）：「完全予約制です。まずは腎臓内科の午前の一般外来を受診してください。」
- 産科 初診：「産科の初診はWEB予約に対応しています。」
- NIPT：「予約制（土曜9:00〜12:00）。当院通院中は受診時、他院は紹介状＋地域連携室。」
- 無痛分娩：「無痛分娩教室への参加が必須（毎月最終週土曜14:30〜）。」
- 人間ドック・検診：「メディカルサポートセンターの専用窓口で承ります。」

## 2. L1応答ルール「外来の予約について」＝短縮版に差し替え（例外ダンプ防止）
```
当院の外来は基本的に予約なしで、診療時間内（受付 月〜土 8:00〜12:00）にご来院いただけます。専門外来など一部は予約制です。
・紹介状をお持ちの方：地域連携室（0586-48-0022）へ
・紹介状をお持ちでない方：予約センター（0586-48-0026）へ
詳しくは診察のご予約ページをご確認ください。
https://www.anzu.or.jp/ichinomiyanishi/area/shinryou_yoyaku/
```
- 歯科WEB／産科WEB／救急 の例外は**各エンティティ側**に持たせ、L1本文からは外す。
