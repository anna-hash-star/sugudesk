# 運用ログ分析：実運用で出る質問 vs 登録済みFAQ（共通項・漏れ観点）

> 目的: 他院（ルナレディースクリニック・AdeBクリニック）の**実運用データ**（患者との会話ログから起票された修正・追加依頼、登録済みFAQ、架電件数）を分析し、
> 「HPを読むだけでは拾えない質問の観点（共通項）」と「登録FAQの漏れパターン」を抽出する。
> ここで得た観点は `faq-extraction-rules.md` §11／`faq-extraction-prompt.md` に反映し、一宮西病院ほか全案件の抽出精度を上げる。
> 分析対象: `チャットボットの改善連携(ルナ).xlsx`（修正153件・リクエスト54件・架電件数）、`【ルナレディース】FAQ.xlsx`（共通1,213問＋各院約100問）、`【AdeBクリニック】FAQ.xlsx`（1,379問＋キャンペーン/インターバル）
> ※会話ログには患者の個人情報が含まれ得るため、本書では個票を残さず観点のみを抽出している。
> 最終更新: 2026-07-01

---

## 0. 要約（ここだけ読めば分かる）

- **登録FAQが1,000問以上あっても、運用開始後3か月で150件超の「答えられなかった／間違えた」が起票された。** FAQの網羅度が高くても、**質問の“観点”が足りないと穴が開く**。穴は下記16観点に集約できる。
- **HPには「やっていること」しか書かれない。運用で最も多い質問は「◯◯はできますか？（＝やっていない）」。** 対応可否（特に**対応していない診療**）を先回りで登録することが最大の効き所。
- **最大のアンチパターンは「わからない質問を全部“お電話ください”に流す」こと。** 依頼シート54件の過半が「電話促しになっているので、対応していない旨／リンク誘導に変えてほしい」。電話に流すほどクリニックの電話は鳴り続ける（架電は1日40〜100件）。**電話は最後の手段**。
- 美容（AdeB）と婦人科（ルナ）で診療内容は全く違うのに、**質問の骨格（料金・予約メニュー・対応可否・受診資格・アクセス/設備・書類・結果確認）は共通**。この骨格を「クリニック共通ベースFAQ」として全案件のテンプレにできる。

### 1-2. クリニックからの依頼（ルナ／54件）— 依頼の“型”
- **「電話促しになっているので、◯◯に変えてほしい」が過半。** 内訳の大半が2種類:
  1. **対応していない診療を明示してほしい**（乳腺炎・マンモ・脱毛・モナリザタッチ・排卵誘発剤・妊活/不妊・アレルギー検査・腹部エコー・利尿剤・男性の受診 等）。
  2. **電話でなくリンク/定型で完結させてほしい**（定期便料金→通販リンク、診療時間、電話受付時間 等）。
- **受入不可の明示**: 大量出血・血尿など「電話でなく“当院では対応できない可能性”を先に伝えて」。
- **回答の取り違え**: 「支払い方法」→オンライン診療の支払いがヒット、「吐き気止め料金」→痛み止め料金がヒット 等、**近い言葉の誤ヒット**。

### 1-3. 架電件数
3〜4月で**1日あたり約40〜100件**の入電。チャットで拾えない質問がそのまま電話に流れている。**チャットの網羅度＝電話削減**という関係が数字で見える。

### 1-4. 登録済みFAQの規模（参考）
- ルナ: 共通1,213問＋町田/川崎/横浜 各約100問。カテゴリ上位＝中絶手術・郵送検査・婦人科健診・月経移動・性感染症検査…（＝診療メニュー単位で厚い）。
- AdeB: 1,379問。上位＝施術・治療案内565／予約・受付95／料金69…（美容も**施術＝診療メニュー単位**で厚い）。
- → **これだけの規模でも穴は開く**。規模でなく観点で潰す。

## 2. 共通項＝実運用で頻出するのに、HP抽出だと漏れやすい「16の質問観点」

HP本文は「提供している診療の紹介」中心。以下は**患者が実際に聞くが、HPに明記されず抽出から漏れやすい**観点。各案件でこの16観点を**チェックリスト**として当てる。

1. **対応可否（やっている／やっていない）** ★最重要
   - 「◯◯はできますか？」。特に**やっていない診療**はHPに書かれないため全て漏れる。近接診療・混同されやすい診療（婦人科なら乳腺/マンモ/妊活/不妊/分娩、美容なら扱わない術式）を**先回りで“対応していない”登録**する。→ 診療対象外テーマ。
2. **個別品目の料金** ★
   - 銘柄・薬剤・検査単体・書類ごとの具体金額（例: 吐き気止め¥220、再発行¥1,100）。HPは代表価格のみのことが多い。→ 診療メニューの料金プラン＋ナレッジに全件。**「電話でも金額を答えられない」場合の方針も要確認**。
3. **保険が効くか／自費か**
   - 検査・治療ごとに「保険診療ですか？」。原則自費・症状ありなら保険、等の切り分け方針。→ 診療メニューの保険種別＋横断FAQ。
4. **初診料・再診料の有無**
   - 「自費は初再診料なし／保険は毎回発生」等。頻出だがHP未記載が多い。→ 料金・支払い横断FAQ。
5. **予約メニューの選び方（予約システム連携特有）** ★
   - 「◯◯は何のメニューで予約？」「相談が2つある時は？」「紹介状持参は？」。症状・目的ごとに**選ぶべき予約枠**を案内。→ 各お悩み・症状／診療メニューに「この予約メニューを選ぶ」導線。
6. **受診資格・条件** ★
   - 年齢（15歳以上／18歳未満は保護者同伴）、性別（男性不可）、性交渉未経験、生理中受診、妊娠週数、かかりつけ有無、保険証なし、対象市区町村。→ 横断FAQ＋応答ルール（複数キーワードで吸収）。
7. **診察・処方の要否**
   - 「診察なしで薬だけ欲しい」「処方のみ受け取り」「再診は必要か」「処方箋が切れた」。→ 診療メニュー運用ルール／横断FAQ。
8. **他院との連携・引き継ぎ**
   - 別院/他院での処方継続、他院検査結果での精密検査、紹介状。「連携病院はあるか」は**事実確認が必須**（ルナは“連携先なし”で誤案内が起きた）。
9. **薬・処方の可否＝医療判断の回避**
   - 特定薬剤の処方可否は「医師判断→受診」で一貫。→ 応答ルール（医療判断回避）。
10. **書類・証明の発行**
    - 各種証明書・領収書再発行・同意書フォーマット/PDF提供・捺印ルール。→ 書類発行 全件ナレッジ＋代表FAQ。
11. **検査結果の受け取り方**
    - 「電話で聞ける？」「来院必須？」「いつわかる？」「アプリ/LINEで見られる？」「解析中とは？」。→ 横断FAQ。
12. **手続き・システム操作（デジタル導線特有）** ★
    - LINE友だち追加/診察券番号、問診票URLが開けない、アカウント削除、氏名変更、購入/受診履歴、定期便の解約・次回発送日。HPに無く、**予約/オンライン診療/LINE基盤に依存**。→ 横断FAQ／応答ルール。導入時にクリニックへ確認。
13. **持ち物・所要時間・服装**
    - 来院時の持ち物、診察の所要時間目安、服装（着脱しやすい等）。頻出だがHP未記載。
14. **キャンセル・変更ルール**
    - キャンセル期限、自動キャンセル条件、**特別ルールのある予約（例: 中絶手術）は通常キャンセルと分けて登録**。
15. **プライバシー配慮**
    - 「親に知られる？」「家に郵送物は届く？」「家族に知られず受診したい」。センシティブ診療（未成年ピル・中絶・性感染症）で必須。→ 各メニューのclinic_note＋FAQ。
16. **繁忙期・特例営業／設備アクセス詳細**
    - GW・年末年始の各院営業日（→お知らせ）。バリアフリー/車椅子トイレ/授乳室/駐輪場/ベビーカー可否/マイナ保険証機（→クリニック設定＋FAQ）。

## 3. 漏れ・失敗のパターン分析（なぜ穴が開くか）

| パターン | 具体 | 対策（登録側でやること） |
|---|---|---|
| **やっていないことが未登録** | 「乳腺炎診てくれる？」に電話促し | 近接・混同されやすい診療を「診療対象外テーマ」に先回り登録（対応可否リスト化） |
| **近い言葉の誤ヒット** | 「吐き気止め料金」に痛み止め料金／「支払い方法」にオンライン診療支払い | 品目・場面を**別名/キーワードで細かく分離**、紛らわしい対は別FAQに分割 |
| **代表価格しかない** | 銘柄別・単体検査の金額が出ない | 料金は**全件をナレッジ**に（RAG回答用）、FAQは代表例 |
| **場面限定で書いてしまう** | 「オンライン診療の支払い」しか無く来院時に答えられない | 一般原則（支払い方法・受診資格等）は**場面非限定の横断FAQ**に |
| **電話への過剰フォールバック** | 何でも「お電話ください」 | §4のメタルール。電話は最後 |
| **動的情報の誤り** | 診療時間・繁忙期営業を本文固定→改定で誤案内 | 変わるものは誘導、特例営業はお知らせ |
| **事実の思い込み** | 「連携病院あり」が実際は無し | HP記載でも**運用実態を要確認**（特に連携・付き添い・院内/院外処方） |

## 4. メタルール（最重要）：電話フォールバックを最小化する

依頼シートが示す通り、**「わからない＝お電話ください」はクリニックの電話を増やすアンチパターン**。回答が確定できない質問は、次の優先順で処理する。

1. **対応していないなら「対応していません」で完結**（＋可能なら代替の受診先を一言）。電話に流さない。
2. **公開情報で答えられるならリンク/定型で完結**（料金ページ・通販ページ・診療時間・電話受付時間 等）。
3. **医療判断・個別性が高いものだけ受診/電話へ**（薬の可否、症状の要否 等）。この時も「なぜ電話か（医師判断のため 等）」を添える。
4. **緊急・受入不可は「電話」でなく先に切り分け**（大量出血/血尿など→当院では対応できない可能性＋救急/専門へ、を先に提示）。

→ 抽出時は各FAQに「これは電話に流していないか？対応外明示 or リンク完結にできないか？」を必ず自問する。

## 5. クリニック共通ベースFAQ（全案件テンプレ）

診療科が違っても骨格は共通。新規案件は、まず下記を**必ず埋める枠**として用意し、そこにHP事実を流し込む（空欄は要確認で先方へ）。

**A. 受診・予約**：予約方法/チャネル ・ 予約メニューの選び方（目的別）・ 初診/再診の料金と流れ ・ キャンセル/変更ルール ・ 予約なし来院の可否 ・ 所要時間目安 ・ 持ち物 ・ 予約枠の解放時期
**B. 料金・支払い**：代表料金 ・ 保険/自費の切り分け ・ 支払い方法（分割可否含む）・ 品目別料金（全件はナレッジ）・ 領収書/明細
**C. 対応範囲（可否）**：やっている診療一覧 ・ **やっていない診療一覧（対象外）** ・ 近接科への誘導
**D. 受診資格・条件**：年齢/保護者同伴 ・ 性別 ・ 保険証の要否 ・ 対象エリア（公費等）・ かかりつけ要否
**E. アクセス・設備**：場所/行き方 ・ 駐車/駐輪 ・ バリアフリー/車椅子/授乳室 ・ 営業日/休診/繁忙期特例 ・ マイナ保険証
**F. 検査・結果**：検査メニュー ・ 当日実施可否 ・ 結果の受け取り方（電話/来院/アプリ・日数）
**G. 書類**：発行できる書類と料金 ・ 再発行 ・ 同意書等のフォーマット提供
**H. デジタル手続き**：予約システム/LINE/オンライン診療の操作・トラブル対応 ・ 履歴/登録情報の確認・変更
**I. プライバシー**：家族/親への通知 ・ 郵送物の配慮
**J. 医療判断・緊急**：症状の要否は受診誘導（医療判断回避）・ 緊急/受入不可の切り分け（救急エスカレーション）
