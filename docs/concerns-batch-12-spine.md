# 脊椎・側彎センター（診療科ベース標準フォーマット）

受付：B棟2階J／整形外科／外来原則予約制。担当表 #spine。小児〜成人の脊柱疾患専門。センター長 川上紀明。

## 構成
- overview：脊柱疾患専門(側彎症/後彎症/脊柱管狭窄/椎間板ヘルニア/頸椎症)・整形外科・受付B棟2階J・外来原則予約制・保存療法第一。
- ナレッジ：対象疾患5分類(先天性側彎/成長期側彎/変性側彎/骨折変形治癒/首背中腰の痛み下肢痛)＋治療の流れ(診察→検査→保存療法→入院精査→手術提案→決定)＋側彎症解説(特発性側彎症=思春期女児・猫背との違い)＋BSPTS研修＋担当表フッター。
- 場所FAQ：B棟2階J・整形外科。
- 診療メニュー：脊椎・側彎症の治療(保存療法/手術)。外来原則予約制。
- お悩み更新：①既存「背骨の変形・側彎症」→ 受付J・脊椎側彎センター・特発性側彎症等別名追加・原則予約制。②既存「腰・首の痛み・足のしびれ(脊椎)」→ 脊椎側彎センター・受付J。
- FAQ：側彎症診てもらえるか／子どもの背骨の曲がり。
