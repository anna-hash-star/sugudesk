# 糖尿病センター（診療科ベース標準フォーマット）

受付：B棟2階O／内分泌・糖尿病内科／M型。担当表 #diabetes。
合併症関連科（眼科・皮膚科・形成外科・腎臓内科）＋栄養指導室が同一エリア集結・チーム医療。

## 構成
- overview：糖尿病専門・合併症関連科集結・重症例受入(DKA/HHS)・受付B棟2階O。
- ナレッジ：対象疾患(2型難渋/急上昇/高度肥満/重篤合併症・1型・肝性・膵性・妊娠・薬剤性・先進デバイスCGM/ポンプ)／糖尿病と合併症(細小血管=目神経腎/大血管=脳心)／治療(食事:栄養士＋療養指導士・低糖質スイーツ／運動:理学療法士／薬物:インスリン外来導入・週1回・ポンプCSII・GLP-1)／フットケア／入院治療例＋担当表フッター。
- 場所FAQ：B棟2階O。
- 診療メニュー：①薬物療法(インスリン/ポンプCSII/CGM/GLP-1) ②療養指導(食事/運動/フットケア)。
- お悩み更新：既存「糖尿病」→ 受付O・糖尿病センター・合併症連携・インスリンポンプ/CGM・1型/妊娠糖尿病 別名追加。M締め。
- FAQ：糖尿病診てもらえるか／インスリンポンプCGM。

## 要確認
各治療・指導の料金・保険。担当表 #diabetes。肥満症センターと同エリアO・GLP-1重複→用途で区別(糖尿病=血糖/肥満症=減量)。
