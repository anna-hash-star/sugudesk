# 診療メニュー／手術・予約導線 テスト項目

目的：診療メニュー未登録の状態で「手術・治療・検査を受けたい」を打ち、①対象メニュー/科が出るか ②予約導線（紹介状あり=地域連携室／なし=まず外来受診）が一貫しているか ③違和感がないか を確認。
チェック観点：科の振り分けは正しいか／存在しない約束をしていないか／予約導線が正しいか／リンクが正しいか／かぶりで誤ヒットしていないか。

## C. 予約導線の一貫性（最重要）
| テスト質問 | 期待する回答 | チェック |

## D. かぶり・振り分けの確認
| テスト質問 | 期待する回答 | チェック |
|---|---|---|
| しびれがある | 原因で科が違う旨（脳神経外科/整形/脳神経内科/循環器）を案内 | 7件の誤ヒット・トリアージできるか |
| 動悸がする | 循環器内科（不整脈）＋甲状腺の可能性 | 甲状腺だけに誤ヒットしないか |
| むくみがある | 心臓/腎臓/リンパ浮腫など複数可能性 | 単一科に誤断定しないか |
| 足がしびれて歩くと休みたくなる | 循環器内科（PAD／末梢動脈疾患） | 脊椎でなくPADに行くか |
