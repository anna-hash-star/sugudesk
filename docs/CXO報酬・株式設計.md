# CXO報酬・株式設計（シード期 SuguDesk）

## 前提整理

| 項目 | 値 |
|------|-----|
| シードプレ | 1.7億円 |
| エクイティ調達 | VC 3,000万 + エンジェル 150万 = 3,150万円 |
| デット（公庫） | 1,000万円（BS擬似資本） |
| 放出比率（既存株主合計） | 約15.5%（VC 14.7% + 佐藤 0.49% + 洋介 0.25%） |
| Founder持分（シード後） | 約84.5% |
| CEO報酬 | 30万円/月（年360万） |
| SOプール（Series A時想定） | 6.7% |
| Series A想定 | プレ5億・調達1億・M24 |

**重要な制約**
1. すでに15.5%放出済 → Series A後にFounder過半割れリスクあり、ここからのSO切り出しはFounder dilutionに直撃
2. CEO報酬が極めて低い（年360万）→ 後発CXOに市場相場（年1,500万〜）を払うと社内不公平感＋ランウェイ毀損
3. 開発はエンジニア業務委託（時給5,000円・月32〜64h）→ フルタイムCTOへの切替は固定費が一気に増える

## 設計の基本方針

### 1. 「共創レベル」と「1号社員レベル」を区別する

| 区分 | 想定キャラクター | エクイティ | 給与 | 形態 |
|------|------------------|-----------|------|------|
| 共同創業者級CTO | フルコミット・リスクを取る・初期から経営参加 | 5〜10%（生株 or SO） | CEOと同水準（30〜50万円/月） | 生株+リバースベスティング推奨 |
| 1号社員CTO | 給料も欲しい・専門性で貢献 | 1〜3%（SO） | 800〜1,200万円/年 | 税制適格SO |
| パートタイムCTO/技術顧問 | 週1〜2日・指南役 | 0.1〜0.5%（SO） | 月10〜30万円 | アドバイザリーSO |

**SuguDeskの状況での推奨：1号社員CTOモデル**
- 既に15.5%放出済のため、共創レベルで5%以上を渡すとSeries A後にFounderが過半数割れする可能性が高い
- 業務委託エンジニアの正社員化（CTO登用）であれば「社内昇格」として給与・SOを設計しやすい

### 2. CXO別のレンジ（SuguDesk向け推奨）

| ロール | 優先度 | SO（シード期付与） | 給与レンジ（年） | 補足 |
|--------|--------|---------------------|------------------|------|
| CTO | 最優先 | 1.5〜3.0% | 800〜1,200万 | プロダクト＝SuguDesk v2責任 |
| COO（BPO責任者） | 次点（M7以降） | 1.0〜2.0% | 700〜1,000万 | BPO事務長の上位レイヤー |
| CFO（パートタイム） | 低（Series Aに向け） | 0.3〜0.5% | 月20〜40万 業務委託 | 資本政策・財務管掌 |
| CRO/営業責任者 | 低 | 0.5〜1.5% | 600〜900万＋インセン | Phase3以降 |

合計でシード期に切り出すSOは **3〜5%程度** に抑える（Series A想定の6.7%プールに収まるよう逆算）。

## エクイティ設計の実務

### 生株 vs ストックオプションの選び分け

- **生株（普通株）**：共同創業者級のみ。リバースベスティングで既得権を制限
  - 4年vest・1年cliff・退職時会社が時価で買戻し可能な株主間契約必須
  - 注意：時価より低額で付与すると給与課税リスク（特にシード後は時価＝1.7億÷100万株＝170円）
- **税制適格SO**：1号社員CTO以下はこちら推奨
  - 権利行使価額 ≥ 付与時時価
  - 付与から2年経過後〜10年以内に行使
  - 年間権利行使1,200万円まで
  - 譲渡禁止
  - 退職時失効が原則
- **信託型SO**：2023年税制改正で給与課税扱いになった（最大55%）→ 慎重に。新規設計では避け、税制適格で組むのが無難

### ベスティング条項（共通）

- 4年クリフ1年（標準）
- 退職時：未vest分は失効、vest済は税制適格SOなら原則失効（or 適格性放棄して残す）
- ダブルトリガーアクセラレーション（M&A＋解雇）：採用時の交渉カード
- Bad leaver条項：故意過失退職時はvest済も失効

### SOプールの切り出しタイミング

現計画ではSeries A時に6.7%とあるが、CTOをシードで採用するなら **シード後すぐに3〜5%プールを切るべき**。

**理由：**
- 採用時に「具体的な%」を提示できないと優秀層は来ない
- Series A時にプールを切る場合、慣行的にプレマネーから差し引くため希薄化はFounder側がほぼ全て被る
- シード期に切れば、現存投資家（Oikaze等）もある程度共有してプールを作るよう交渉できる（ただし投資契約のSOプール条項要確認）

**推奨：シード後CTO付与用に2〜3%、その後の採用用に追加2%、合計5%プールを早期に設定**

## 報酬設計の実務

### 「Founder低給→CXO高給」のギャップ問題

CEOが30万/月のままCTOに月80万を出すと、社内の上下関係が逆転する。打ち手：

1. **CEO報酬をCTO採用と同時に引き上げる**（例：CEO 60万、CTO 70〜80万）
   - 採用CTOがCEOの2倍だと心理的にきつい。1.2〜1.4倍が落としどころ
2. **基本給を市場の50〜70%に抑え、SOで埋める**
   - 例：CTO 年800万＋SO 2.5% vs 市場の年1,500万
   - 候補者にはこの「給与減分の現在価値」と「SOの期待値」を明示するシートを渡す
3. **業績連動ボーナス**
   - Series Aクローズ・MRR目標達成で一時金（例：MRR 500万円達成で200万）

### ランウェイへの影響試算（参考）

シード調達3,000万 + 公庫1,000万 = 4,000万円キャッシュ。

| シナリオ | 月次バーン | ランウェイ |
|----------|------------|------------|
| 現計画（CTOなし） | 約100万 | 40ヶ月 |
| CTO月80万追加（給与+社保） | 約190万 | 21ヶ月 |
| CTO月80万＋COO月70万 | 約280万 | 14ヶ月 |

→ **CTOフルタイム化はM12までにSeries Aブリッジ or 売上で回収する設計が必須**。
→ COO/CFO同時採用は危険。CTOを先行させ、BPO売上立ち上げ（Phase2）後にCOO採用が現実的。

## SuguDesk向け具体案（推奨パッケージ）

### ケースA：業務委託エンジニアをCTOに登用する場合
```
役職      ：CTO（プロダクト＆エンジニアリング全責任）
形態      ：正社員フルタイム
給与      ：年900万円（月75万）+ 期末賞与最大100万
SO       ：2.0%（税制適格SO）
ベスト    ：4年・1年クリフ
入社時    ：M3〜M6を目処（SuguDesk v2リリース直前）
備考      ：CEO報酬を月50万に同時引き上げ
```

### ケースB：外部からシニアCTOを招聘する場合
```
役職      ：CTO（共同創業者級として迎える）
形態      ：正社員フルタイム
給与      ：年1,200万円（月100万）
SO       ：3.0%（税制適格SO、4年・1年クリフ）
追加     ：M&A時ダブルトリガーアクセラレーション50%
備考      ：実績によっては「共創扱い」で生株1〜2%上乗せ検討
　　　    　ただしFounder dilution注意
```

### ケースC：パートタイムCTO＋シニアエンジニアの組み合わせ（最も低リスク）
```
パートタイムCTO（技術顧問格）
　形態   ：業務委託 週2日
　報酬   ：月30万円
　SO    ：0.3%（4年・1年クリフ）

シニアフルスタックエンジニア（実装責任者）
　形態   ：正社員
　給与   ：年800万円
　SO    ：0.5〜1.0%
```

→ **Phase1〜2はケースAまたはCを推奨**。ケースBはARR1,000万円超え＆Series A確度が高い段階で。

## SOプール再設計案（cap tableに反映するなら）

現状の6.7%（Series A時）を以下に変更：

| ラウンド | プール累計 | 用途 |
|----------|----------|------|
| シード後（追加配賦） | 5.0% | CTO 2〜3%、その他early hires 2〜3% |
| Series A時 | 8.0%（差分3.0%追加） | Series A後の幹部採用用 |

**前提シートB51の変更：**
- A51_seed/B51_seed: シード後SOプール = 0.05
- A51/B51: Series A後SOプール累計 = 0.08

これによるFounder持分の影響（Series A後）：
- 現計画：Founder ≈ 65〜68%
- 上記改定：Founder ≈ 60〜63%
- 差分は3〜5pt → 容認可能な範囲

## チェックリスト（CXO採用前にやること）

- [ ] 投資契約書のSOプール条項を確認（Oikazeとの契約に「Series A前のSO発行は事前承諾」等の条項がないか）
- [ ] 株主間契約のFounder株式の譲渡制限・買戻し条項を確認
- [ ] 税制適格SOの要件を税理士・弁護士とレビュー
- [ ] CTOへの提示用「給与＋SO期待値」シートを作成（Series A・Bでの希薄化シナリオ込み）
- [ ] CEO報酬の引き上げタイミング・幅をボードで合意
- [ ] CTO候補に提示する「役割定義書（プロダクト・組織・採用責任の範囲）」を作成
- [ ] バックグラウンドチェック・リファレンスコール体制
- [ ] 試用期間（3〜6ヶ月）と早期離脱時のSO/給与条件を契約に明記

## まとめ：最初の一手の推奨

1. **採用順序**：CTO → COO（BPOスケール時） → CFO（Series A前） → CRO（Series A後）
2. **CTO設計**：SO 2.0〜2.5%、給与 年900万円、4年vest・1年cliff、税制適格SO
3. **SOプール**：Series A時6.7%ではなく、**シード後に5%先行設定**を投資家と交渉
4. **CEO報酬**：CTO採用と同時に月50〜60万円に引き上げ（社内バランス）
5. **ランウェイ管理**：CTOフルタイム化でランウェイは21ヶ月程度。M12までにMRR 300万円超え or Series Aブリッジが必須
