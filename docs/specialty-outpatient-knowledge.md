# 専門外来のご案内（症状・お悩み・予約から探す）

> 統合ナレッジ（テスト用）。各項目は「症状キーワード＋対応科・外来＋予約案内」で自己完結。
> 標準予約文からは「受診時に医師が専門外来・検査をご案内・ご予約します」という断定（＝紹介の約束）を削除。
