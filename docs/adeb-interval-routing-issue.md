# 【不具合報告】施術間隔・同日施術の質問で、間隔ナレッジが採用されない

AdeBクリニック秋田院 / SuguDesk（staging）

## 概要
「AとBは同日に施術できますか」「AとBの間隔は」等の**施術の組み合わせ質問**で、該当する
**施術間隔ナレッジ記事が検索でヒットしているにもかかわらず**、採点段階で
`topic_mismatch_for_structured_answer` により `一致度 低` とされ**採用されない**。
結果、メニュー解説記事（treatment_menu）から一般的な回答が生成され、
**具体的な間隔・同日可否が答えられない**。

## 再現（2件とも同一挙動）

### ケース1
- 質問：「レーザートーニングとテノールネオを同じ日に施術できますか？」
- 候補：`テノールネオの施術間隔`(低/topic_mismatch)、`レーザートーニングの施術間隔`(低/topic_mismatch)
- 採用根拠：`テノールNEO（ネオ）について` + `reservation_rule(WEB予約)` + `treatment_menu(レーザートーニング)`

### ケース2
- 質問：「トーニングとテノールネオは同時に施術可能ですか？」
- 正規化：「トーニングとテノールネオの同時施術の可否」／抽出KW：レーザートーニング, テノールネオ（正常）
- 候補：`テノールネオの施術間隔`(低/topic_mismatch)、`レーザートーニングの施術間隔`(低/topic_mismatch)
- 採用根拠：`テノールNEO（ネオ）について` + `reservation_rule` + `treatment_menu(テノールNEO)`

## 観測 vs 期待
- **観測**：間隔記事は候補に上がる（＝検索・キーワードは機能）。しかし
  `topic_mismatch_for_structured_answer` で除外され、grounding に渡らない。
- **期待**：間隔記事（または間隔データ）を根拠に、具体値を回答する。
  - 正解例（レーザートーニング×テノールネオ）：**別部位は同日可／同部位は1週間**
    （テノールネオが先の場合は会員・回数券で同日可）

## 原因仮説
意図分類が本質問を「構造化データ（treatment_menu / reservation_rule）で答える」経路に振り、
`施術間隔` トピックの記事を「構造化回答にはトピック不一致」として弾いている。
＝**コンテンツ不足ではなく、採点・ルーティングのゲート**が原因。
（コンテンツ側の粒度・言い回し・別名は対応済みで、検索ヒットは実現できている）

## 依頼（いずれか）
1. **「施術間隔・同日施術・併用」意図**を追加し、その意図では
   `施術間隔` ナレッジ／間隔データを**構造化回答の正ソースとして許可**（topic-mismatch ゲートを通す）。
2. もしくは同意図では、施術名を2つ抽出し
   **(先, 後) の決定論ルックアップ**で該当間隔を返す（曖昧検索・生成を経由しない）。

## データ
- 全ペア（先/後/間隔_raw）：`docs/adeb-faq-review/interval_all_pairs.csv`（34メニュー×1,051ペア）
- 元マトリクス：`docs/adeb-faq-review/interval_source.csv`
- 別名の傾向：フォト→フォトフェイシャル、トーニング→レーザー/ピコトーニング、テノール→テノールNEO 等（keywords 反映済み）

## 補足（対象外だが要考慮）
`Lマドンナ` `メソスキン` `血管腫レーザー`(＝赤み治療) 等はマトリクス34施術に無い個別メニュー。
「薬をやめてどのくらいでボトックス可か」等の**薬→施術**の間隔もマトリクス外。別途対応が必要。
