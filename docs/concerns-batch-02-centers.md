# お悩み・症状 一括登録バッチ02（センター由来・新規症状）

既存お悩み（膵胆道・IBD・動悸/不整脈・肥満症・透析予防/シャント・脊椎しびれ）と重複するセンターは除外。
公開ON必須。リンクはチップ形式。M締め＝「まず午前外来（予約不要）＋紹介状ありは地域連携室」。

## 【下肢静脈瘤（足の血管が浮き出る・むくみ・だるさ）】
- 別名・略称：下肢静脈瘤／足の血管が浮き出る／足のむくみ／足がだるい／こむら返り／レーザー治療 足／静脈瘤
- 一般説明：足の静脈の弁が働かなくなり、血管が浮き出たり、むくみ・だるさが出る病気です。放置すると皮膚炎や潰瘍になることがあります。
- 主な症状：足の血管がぼこぼこ浮き出る／足のむくみ・だるさ／こむら返り／皮膚の色素沈着・かゆみ
- 当院の治療方針：下肢静脈瘤は、下肢静脈瘤センターで対応しています（受付A棟2階G）。レーザー治療を含む低侵襲治療を行っています。まずは該当科の午前の一般外来（受付 月〜土 8:00〜12:00）を受診してください（予約不要）。紹介状をお持ちの方は、地域連携室（0586-48-0022／月〜金 8:00〜17:00・土 8:00〜12:00）へご連絡ください。詳しくはこちらをご確認ください。<br>[下肢静脈瘤センターのご案内ページ](https://www.anzu.or.jp/ichinomiyanishi/center/vein/)
- 関連診療科：循環器内科・心臓血管外科　※所属科は先方確認

## 【股関節の痛み（変形性股関節症）】
- 別名・略称：股関節が痛い／股関節痛／変形性股関節症／寛骨臼形成不全／脚の付け根が痛い／人工股関節
- 一般説明：股関節の軟骨がすり減る変形性股関節症などの病気です。進行すると靴下の着脱や爪切りが難しくなり、歩行がつらくなることがあります。
- 主な症状：脚の付け根が痛い／歩くと股関節が痛い／靴下の着脱・爪切りがつらい／左右の脚の長さの差
- 当院の治療方針：股関節の痛み（変形性股関節症など）は、整形外科（股関節センター）で対応しています（受付B棟2階J）。人工股関節手術も行っています。まずは整形外科の午前の一般外来（受付 月〜土 8:00〜12:00）を受診してください（予約不要）。紹介状をお持ちの方は、地域連携室（0586-48-0022／月〜金 8:00〜17:00・土 8:00〜12:00）へご連絡ください。詳しくはこちらをご確認ください。<br>[股関節センターのご案内ページ](https://www.anzu.or.jp/ichinomiyanishi/center/hipjoint/)
- 関連診療科：整形外科

## 【肩の痛み（四十肩・五十肩・腱板断裂）】
- 別名・略称：肩が痛い／肩が上がらない／四十肩／五十肩／腱板断裂／石灰沈着性腱板炎／肩関節脱臼／投球障害肩／肩こり 痛い

## 【骨折・ケガ（外傷）】
- 別名・略称：骨折／ケガ／外傷／骨が折れた／高齢者の骨折／開放骨折／骨盤骨折／脱臼

## 【糖尿病】
- 別名・略称：糖尿病／血糖値が高い／HbA1c／糖尿病センター／糖尿病 フットケア／インスリン
- 一般説明：糖尿病に関するご相談です。多くは症状がないまま進行し、目・神経・腎臓などの合併症のリスクが高まります。複数の診療科・専門スタッフによるチーム医療で対応します。
