# LP量産のためのAI指示ガイド（マスタープロンプト＋テーマ別ブリーフ）

ピルLP（ルナレディースクリニック）を基準品質として、他テーマのLPを同等以上の質で量産するためのプロンプト設計ガイド。

構成:
1. なぜあのLPは質が高いのか（品質の分解）
2. マスタープロンプト（毎回そのままコピペする共通指示）
3. テーマ別ブリーフ（テーマごとに埋める変数シート）
4. 量産ワークフローとセルフレビュー用プロンプト
5. 記入例（アフターピルの場合）

---

## 1. なぜあのLPは質が高いのか（品質の分解）

AIに「良いLPを作って」と言っても質が安定しないのは、良さの正体を指示に落とせていないから。ピルLPの品質は以下の7要素に分解できる。**この7つを毎回指示に含めることが再現の鍵。**

### ① 説得の順番（ストーリー構成）が固定されている
「共感 → 自分ごと化 → 教育 → 不安の解消 → 行動の簡単さ → 信頼 → 行動」の順。

| # | セクション | 役割 |
|---|---|---|
| 1 | ヒーロー（H1＋デュアルCTA＋信頼バッジ） | 共感的な問いかけで入る。売り込まない |
| 2 | 症状セルフチェック（タップ式チップ） | 読者を「自分の話だ」と当事者化させる |
| 3 | 基礎知識（〜とは） | 教育コンテンツでSEOと信頼を両取り |
| 4 | ベネフィット（カード型・出典付き） | 効果を根拠つきで提示 |
| 5 | 種類と選び方（比較表） | 「選べる・自分に合うものがある」と示す |
| 6 | 副作用・リスク（アコーディオンQ&A＋数値表） | **不安に正面から答える。ここが信頼の核** |
| 7 | 受診の流れ（来院/オンラインのタブ） | 行動のハードルを下げる |
| 8 | 費用（料金表＋保険適用の説明） | 価格の不安を消す |
| 9 | 医師紹介（写真＋メッセージ） | 人の顔で最後の一押し |
| 10 | FAQ（アコーディオン＋JSON-LD） | 残った疑問の受け皿＋SEO |
| 11 | 最終CTA → 店舗一覧 → 免責フッター | 行動導線の締め |

### ② 不安への誠実さ（YMYL対応）が信頼をつくる
- リスクを隠さず、**客観的な数値の比較表**で見せる（例: 血栓症の発症頻度を「非服用者/服用者/妊娠中/産後」で並べ、相対的に低いと自分で判断させる）
- 「ガイドラインの結論」「ポイント」のfact-boxで一次情報を明示
- 断定的な効能表現を避け、「医師が提案」「〜とされています」で医療広告ガイドライン・薬機法に配慮
- フッターに免責事項

### ③ CVの仕掛けが多層
- ヒーローにデュアルCTA（来院/オンライン）＋補足注記（※初回は来院が必要 等）
- ヒーローを過ぎたら出現するスティッキーCTAバー
- チャットFAB（吹き出し付き）
- **セルフチェックの結果次第でCTAが変わる**（該当0個→ソフトに「チャットで質問」、5個以上→強く「LINEで相談」）。押し付けず、温度感に合わせる

### ④ デザイントークンで統一されている
- `:root` のCSS変数に全色・フォント・余白を集約（ネイビー＋テーマカラー＋LINE緑）
- 見出しは丸ゴシック系ディスプレイフォント（Zen Maru Gothic）、本文はNoto Sans JP
- `clamp()` によるレスポンシブタイポグラフィ、`--py:80px` のセクションリズム

### ⑤ マイクロインタラクションが「安っぽさ」を消す
- H1のマーカー引きアニメーション、スクロール連動フェードイン（IntersectionObserver）
- 背景のきらめき（sparkle）、アコーディオン、タブ、チェックの進捗バー
- すべてvanilla JSで1ファイル完結（依存ライブラリなし）

### ⑥ SEOが構造に組み込まれている
- title/meta descriptionに「悩みワード＋地域名」
- FAQPage JSON-LD（構造化データ）
- h1→h2の意味的な階層、教育セクションが検索意図（「〜とは」「副作用」「費用」）をカバー

### ⑦ モバイルファースト
- `100svh` ヒーロー、下部スティッキーバー分の `padding-bottom`
- タップ前提のUI（チップ、アコーディオン）、768px/1024pxの2段ブレークポイント

## 2. マスタープロンプト（共通指示・毎回コピペ）

テーマに関係なく毎回そのまま渡す指示。`【】` はテーマ別ブリーフ（§3）の値で埋める。

```
あなたは医療機関のLP制作を専門とするWebデザイナー兼コピーライターです。
以下の仕様で、1ファイル完結のHTML LPを作成してください。

## 成果物の形式
- 単一のHTMLファイル。CSS・JSはすべてインライン。外部依存はGoogle Fontsのみ
- 見出し: Zen Maru Gothic（またはブリーフ指定フォント）、本文: Noto Sans JP
- :root のCSS変数でデザイントークンを定義（ブランド色・テキスト色・余白・角丸）
  ベース: ネイビー #1e2a3a（テキスト・信頼感）＋テーマカラー【メインカラー】＋LINE緑 #06C755（CTA）
- モバイルファースト。ヒーローは min-height:100svh、ブレークポイントは768px/1024px
- 画像はプレースホルダー（後で差し替える前提で alt を具体的に書く）

## ページ構成（この順番を厳守）
1. ヒーロー: 共感型のH1（問いかけ・寄り添い型。売り込み禁止）＋リード文
   ＋デュアルCTA（【CV1】/【CV2】）＋注記＋信頼バッジ3つ（【信頼要素】）
2. セルフチェック: 【症状・悩みチェック項目7個】をタップ式チップで。
   選択数に応じて進捗バーの色とメッセージとCTAが変化
   （0個=ソフトな案内 / 1-2個=軽い提案 / 3-4個=受診推奨 / 5個以上=強い受診推奨＋LINE CTA）
3. 基礎知識: 「【テーマ】とは」を検索意図に答える教育コンテンツとして。
   比較カード（【対比軸】）＋信頼性ボックス（当院の体制・実績）
4. ベネフィット: 【できること・効果 4〜6個】をカード型グリッドで。各カードに出典を小さく明記
5. 種類と選び方: 【選択肢の比較表】。表はモバイルで横スクロール可能に
6. 不安・リスクへの回答: 【よくある不安 4〜6個】をアコーディオンQ&Aで。
   - リスクは客観的な数値の比較表で示す（隠さない・相対化して見せる）
   - 各回答の最後に「ポイント」「ガイドラインの結論」のfact-boxを置く
7. 受診の流れ: 来院/オンラインをタブで切り替え。番号付きステップ（3〜5ステップ）
8. 費用: 料金表＋【保険適用の説明】＋注記（自費/保険、初診料等の但し書き）
9. 医師紹介: 写真＋名前＋肩書＋患者への語りかけメッセージ（引用符デザイン）
10. FAQ: 【FAQ 8〜12問】をアコーディオンで。同内容をFAQPage JSON-LDとして埋め込む
11. 最終CTA: 感情に寄り添う見出し＋メインCTA＋安心の注記
12. 店舗一覧: 【店舗情報】をカードで。各カードに予約ボタン
13. フッター免責: 医療広告ガイドライン準拠の免責文

## CV導線
- CVリンク先はすべて【CVリンクURL】
- ヒーロー通過後に表示されるスティッキー下部CTAバー（デュアルボタン）
- 右下にチャットFAB＋吹き出し（「【チャット吹き出し文言】」）
- CTA文言は「予約する」より心理的ハードルの低い言葉を優先（「相談する」「聞いてみる」）

## コピーライティングの原則
- トーン: 寄り添い・非断定。「〜しませんか」「一緒に」「大丈夫」。恐怖訴求・煽り禁止
- 医療広告ガイドライン・薬機法を遵守:
  - 効果の断定（「必ず治る」「absolutely安全」）禁止。「〜とされています」「医師が判断します」
  - 最上級表現（No.1、最高）・他院比較・体験談の治療効果訴求は禁止
  - 数値・統計は必ず出典（学会ガイドライン・公的機関）を付記する
- 不安への回答は「否定しない→事実（数値）→当院の対応→ポイント要約」の順で書く
- 1文は短く。漢字を開き、体言止めを避け、リズムのある口語に

## インタラクション（vanilla JSのみ）
- セルフチェックのスコア連動UI
- アコーディオン（開閉時に他を閉じる）、タブ切り替え
- スクロール連動フェードイン（IntersectionObserver, .fu/.v パターン)
- H1キーワードへのマーカー引きアニメーション
- スティッキーCTAの出現制御（ヒーロー通過判定）

## SEO
- title: 「【メインキーワード】｜【クリニック名】」形式で32文字以内目安
- meta description: 悩みワード＋提供価値＋地域名を含め120文字前後
- FAQPage JSON-LD、h1は1つ、セクション見出しはh2
- 教育セクションで「【テーマ】とは」「副作用」「費用」「流れ」の検索意図を網羅

## 禁止事項
- 外部CSS/JSライブラリ（Bootstrap, Tailwind CDN, jQuery等）
- ダミーの「Lorem ipsum」（日本語の実コピーを書く）
- 出典のない統計数値、効果の断定、恐怖・羞恥を煽る表現
```

## 3. テーマ別ブリーフ（テーマごとに埋める変数シート）

マスタープロンプトの後ろに付けて渡す。**ここの充実度がLPの質を直接決める。**
特に「よくある不安」と「数値・出典」は、AIに考えさせず人間が一次情報を渡すこと。

```
## テーマ別ブリーフ

### 基本情報
- テーマ（診療・商品）: 【例: アフターピル / 医療脱毛 / AGA / ブライダルチェック】
- クリニック名・拠点: 【例: ルナレディースクリニック（町田・川崎・横浜）】
- ターゲット像: 【年齢層・状況・検索の瞬間の感情。例: 20-30代女性、避妊失敗直後で焦りと羞恥がある】
- 検索キーワード（SEO）: 【メインKW＋サブKW 3-5個】
- メインカラー: 【HEX。テーマの感情に合わせる（安心=ピンク/緑、誠実=青など）】

### CV設計
- CV1（第一目標）: 【例: LINE予約】 リンク: 【URL】
- CV2（第二目標）: 【例: オンライン診療予約】 リンク: 【URL】
- CTA注記: 【例: ※初回処方は来院が必要です】
- チャット吹き出し文言: 【例: 「〇〇のこと、何でも聞いてください」】
- 信頼バッジ3つ: 【例: 駅直結 / 夜間・土日診療 / 24時間チャット対応】

### セルフチェック項目（7個）
【読者が「あるある」と頷く具体的な症状・状況を7つ。抽象語でなく行動レベルで書く。
例: 「毎月、痛み止めが手放せない」「痛みで仕事や学校を休む」】
1. …
7. …

### 教育コンテンツの素材
- 「〜とは」の要点: 【3-4段落分の事実。仕組み・種類・位置づけ】
- 対比軸（比較カード）: 【例: OC vs LEP / 一相性 vs 三相性 / 医療脱毛 vs エステ脱毛】
- ベネフィット4-6個と各出典: 【効果＋出典（学会名・ガイドライン名・年）】

### 不安・リスク素材（最重要。必ず一次情報を渡す）
- よくある不安4-6個: 【例: 太る? 血栓症は? 将来妊娠できる?】
- 各不安に対する事実と数値: 【比較表にできる形で。例: 発症頻度を対象群別に】
- 出典: 【ガイドライン名・公的機関名】
- 危険サインがあれば: 【例: ACHES のような受診目安】

### 選択肢・料金
- 種類の比較表データ: 【薬剤名/プラン名、特徴、向いている人、価格】
- 料金表: 【項目・税込価格・保険適用の有無】
- 料金の注記: 【初診料、ジェネリック、定期配送などの但し書き】

### 受診の流れ
- 来院の場合: 【ステップ3-5個】
- オンラインの場合: 【ステップ3-5個】
- 制約: 【例: 治療目的の初回はオンライン不可】

### FAQ（8-12問）
【実際に患者から聞かれる質問を優先。回答は2-4文の事実ベースで】

### 医師・店舗
- 医師: 【名前・肩書・経歴・患者へのメッセージ（本人の言葉らしさ）】
- 店舗: 【店舗名・アクセス・診療時間・予約リンク】

### 法的注意（テーマ固有）
【例: 自由診療である旨 / 未承認機器の注記 / 効果の個人差 など】
```

## 4. 量産ワークフロー

### 手順（1テーマあたり）
1. **ブリーフを埋める（人間の仕事・30-60分）**
   - 不安・数値・出典・FAQは必ず一次情報（ガイドライン、院内の実データ、実際の患者質問）から
   - ここを空欄でAIに任せると、それらしいが根拠のない数字を書く（ハルシネーション）。**医療LPでは致命的**
2. **マスタープロンプト＋ブリーフを1メッセージで渡して生成**
3. **セルフレビューをAIにやらせる**（下のレビュープロンプト）
4. **人間の最終チェック**: 数値と出典の照合、薬機法・医療広告ガイドライン、リンク先、店舗情報
5. 画像差し替え・計測タグ挿入・公開

### セルフレビュー用プロンプト（生成直後に投げる）
```
作成したLPを以下の観点で自己監査し、問題点を修正した完全版を出力してください。

【法令】効果の断定/最上級表現/出典のない数値/体験談による効果訴求がないか
【構成】11セクションが順番通り揃っているか。H1は1つか。JSON-LDとFAQ本文が一致しているか
【CV】ヒーロー・スティッキー・チェック結果・最終CTAの4導線すべてが機能するか。
     リンク切れ（href="#"）が残っていないか
【モバイル】375px幅で横スクロールが発生しないか。表はスクロールコンテナに入っているか。
     スティッキーバーがコンテンツを隠さないか（body padding-bottom）
【コピー】煽り・恐怖訴求になっていないか。不安への回答が「否定しない→事実→対応→要約」の順か
【JS】アコーディオン・タブ・チェック・スクロール出現がエラーなく動くか
```

### 修正指示のコツ
- 「もっと良くして」ではなく**基準LPとの差分**で指示する: 「ピルLPの副作用セクションのように、リスクを比較表で相対化して」
- コピーの直しはトーンの参照例を渡す: 「『自分に合ったピル、一緒に見つけませんか？』と同じ温度感でH1を5案」
- デザインの直しはトークン単位で: 「--pk系の変数だけ差し替えてテーマカラーを#4A90D9系に」

### 品質を上げる「渡すと効く」素材リスト
| 素材 | 効果 |
|---|---|
| 基準LP（ピルLP）のHTMLそのもの | 構成・トーン・CSS設計を丸ごと踏襲させられる。**最も効く** |
| 実際の患者からの質問リスト | FAQと不安セクションが「本物」になる |
| 学会ガイドラインの該当数値の抜粋 | 数値のハルシネーションを防ぐ |
| 競合LPのURL・スクショ | 「これはやらない」の差別化指示に使える |
| 院内の実績数値（症例数・満足度など） | 信頼性ボックスの具体性が上がる（出典明示できるもののみ） |

## 5. 記入例（アフターピルの場合・抜粋）

```
- テーマ: アフターピル（緊急避妊薬）
- ターゲット像: 10-30代女性。避妊に失敗した直後。焦り・不安・羞恥。「今すぐ」「間に合うか」が最大の関心
- 検索KW: アフターピル 当日 / アフターピル 何時間以内 / 緊急避妊 オンライン
- メインカラー: 落ち着いたティール系（緊急時に煽らない色）
- CV1: 当日オンライン診療 / CV2: 来院予約
- 信頼バッジ: 最短当日発送 / 土日夜間対応 / 匿名チャット相談可
- セルフチェック → このテーマでは「状況チェック」に変える:
  「避妊に失敗してから24時間以内」「72時間以内」「120時間以内」…
  → 選択に応じて「まだ間に合います。〇〇時間以内なら有効率△△%（出典）」と経過時間別の案内を出す
- 不安素材: 「本当に効く?」(72時間以内で約85%妊娠阻止・日本産科婦人科学会)、
  「副作用は?」「親や周囲に知られない?」「保険証は必要?」
- トーン注意: 羞恥・自責を刺激しない。「あなたは悪くない」「よくあるご相談です」を必ず入れる
```

構成テンプレは共通でも、**セルフチェックの意味づけ（症状→状況→悩み度）とトーンの重心はテーマごとに読み替える**。ここだけは毎回ブリーフで明示すること。
