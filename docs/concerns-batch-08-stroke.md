# 脳卒中センター（診療科ベース標準フォーマット）

脳神経内科＋脳神経外科合同。SCU・24時間365日脳卒中ホットライン(2016〜年間800-900件)。血管内治療専門医4名。
★最重要：脳卒中は緊急(Time is Brain)。急性症状は119。急性期はM型ではなく応答ルール(緊急エスカレーション)。

- ナレッジ：体制(ホットライン・SCU看護3:1・ハイブリッド治療・原因探索/長時間心電図・早期リハ休日含む)＋脳卒中の定義＋担当表フッター。
