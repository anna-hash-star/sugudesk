# 不整脈センター（診療科ベース標準フォーマット）

受付：A棟2階G／循環器内科／M型（まず循環器内科の午前外来へ）。担当表 #circulatory。
日本不整脈学会・日本心電学会認定 不整脈専門医研修施設。

## 構成
- overview：不整脈専門センター（心房細動・粗動・上室頻拍・期外収縮・心室頻拍細動）、アブレーション/デバイス治療、受付A棟2階G。
- ナレッジ：対象不整脈＋治療全件（経皮的カテーテル心筋焼灼術/クライオバルーン/PFA 2024.11〜/ペースメーカ・リードレス/ICD/CRT/S-ICD/植込み型心電計/抗不整脈薬/抗凝固/電気生理学検査）＋新技術（CO2心外膜穿刺2024・ARV mapping）＋担当表フッター。
- 場所FAQ：A棟2階G。
- 診療メニュー：①カテーテルアブレーション（経皮的/クライオ/PFA）②ペースメーカ・植込み型デバイス治療（ペースメーカ/リードレス/ICD/CRT/S-ICD/植込み型心電計）。
- お悩み更新：既存「動悸・脈の乱れ」→ 受付A棟2階G・不整脈センター・心房細動等の別名追加。甲状腺併記維持。M締め。
- FAQ：不整脈のカテーテル治療／心房細動の治療。
- リンクはチップ形式。

各治療の料金・保険・入院日数・所要時間。担当表アンカー不整脈専用なし(#circulatory)。
