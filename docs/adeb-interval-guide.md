# AdeBクリニック秋田院 ― 施術間隔表のテキスト化・投入ガイド

施術間隔マトリクス（`_______20250309_ver.csv`、34列×33行）を**表のまま貼らず**、
チャット（RAG）が引ける形に分解・生成しました。方針は **表を正に全面リプレース**。

## 生成物（管理画面取込用）
| ファイル | 内容 | 件数 | 取込先 |
|---|---|---|---|
| `docs/adeb-faq-review/interval_faqs.csv` | 1セル=1Q&A（`question_clean/answer_clean/category=施術間隔/keywords`） | **1,051** | faqs（既存 faq_interval 633件を置換） |
| `docs/adeb-faq-review/interval_summaries.csv` | 先の施術ごとの「間隔一覧」記事（title/category/body） | **34** | knowledge_articles |
| `docs/adeb-faq-review/interval_knowledge.csv` | フッター注釈の構造化（title/type/body） | **8** | knowledge_articles / answer_rules |

## 変換ロジック（品質の要点）
- **表の向き**: 列＝先に受けた施術 / 行＝次に受けたい施術 / セル＝あける間隔（既存FAQ「A後のB」と一致を確認済み）
- **「（）」記法**: 括弧なし＝同部位の間隔＋「別部位なら同日可」を明記／括弧つき＝別部位の間隔として出力
- **特殊トークン正規化**: 同日可・翌日以降・治療完了後N週間・上皮化後N週間・トレチのみN週間・`-`（対象外＝除外）
- **`※``▲`の注釈展開**: ボトックス4ヶ月/脱毛特例/サーマクール6ヶ月/ピーリング/フォト/トーニング/ハイドラ併用/CO2初回/そばかすスポット 等を回答末尾に補足
- **keywords**: 先後の施術名＋括弧除去名＋「施術間隔/間隔/いつ/あける」

## 投入手順（全面リプレース）
1. 既存 `faq_interval` 633件を**バックアップ**（エクスポート）後、非公開化 or 削除
2. `interval_faqs.csv` 1,051件を faqs（category=施術間隔）へインポート
3. `interval_summaries.csv` 34件を knowledge_articles へ
4. `interval_knowledge.csv` 8件を knowledge_articles へ（安全系2件は answer_rules/unsupported として登録・要レビュー）
