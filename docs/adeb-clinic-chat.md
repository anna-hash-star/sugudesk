## 6. 公開（チャット稼働）に向けた残作業

このリポジトリ内で対応可能なのは上記ナレッジの保管・整備までです。実際にチャットを
稼働させるには、以下のいずれか（プラットフォーム依存）が必要です。

- **新基盤（staging.app.sugudesk）の場合**: 管理画面のテナント/クリニックへ
  `adeb-data.json` をインポート → 回答確認 → Widget Key 発行 → HPへ設置
- **Dify の場合**: `lib/clients.js` の `adeb` に `difyToken`（+ `brandColor`）を設定すると
  `/chat/adeb` の iframe が有効化。HP埋め込みは `public/luna_fab_test.html` と同型の
  FABウィジェットを AdeB 用に複製（要 Dify トークン）

> 必要情報（AdeB の Dify トークン or 新基盤の Widget Key、ブランドカラー）を頂ければ、
> 上記の設置まで対応します。
