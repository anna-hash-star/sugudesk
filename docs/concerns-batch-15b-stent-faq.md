# ステントグラフト血管センター よくあるご質問（全22問・貼り付け用）

出典：center/stent/faq/。事実主義・ページ本文どおり。関連診療科＝心臓血管外科（ステントグラフト血管センター）。公開ON。
各FAQ末尾に案内チップ：詳しくはこちらをご確認ください。<br>[ステントグラフト血管センターのご案内ページ](https://www.anzu.or.jp/ichinomiyanishi/center/stent/)

---

1. 動脈瘤といわれたが症状がない。調べたほうがいい？
→ 一度調べることをおすすめします。動脈瘤にも様々な種類があり、部位によっては脳神経外科の受診が必要なことも。実際に動脈瘤があっても経過観察で十分なことが多く、動脈瘤＝治療とは限りません。治療が必要か・経過観察でよいかをはっきりさせるため一度専門病院の受診を。

2. 胸部大動脈瘤といわれたが大きくない。破裂の危険は？
→ 全くないとは言い切れません。大きくなるほど破裂の危険が高まりますが小さくても絶対に破裂しないとは限りません。一般に胸部は5.0〜6.0cmまで経過観察されることが多いが急に大きくなることもあり、定期的なCT検査が必要。定期診察で早期発見・早期治療が可能。

3. 大動脈疾患にならないためには？
→ 大原則は禁煙。喫煙は血管に悪影響で呼吸機能も低下。大動脈疾患は生活習慣病の一環で、糖尿病・高血圧・脂質異常症などの予防が重要。

4. 他院で「手術は不可能」と言われた。なんとかならないか？
→ 手術可否は全身状態だけでなく生活環境・家族構成など社会的要素も含め考慮。ある病院で不可能でも他院で可能と判断されることも。専門病院によるセカンドオピニオンを。

5. 高齢でも手術は可能？
→ 年齢だけで可否は決まらない。80歳以上でも身の回りのことがある程度できれば十分手術可能。

6. 余病（持病）があっても手術は可能？
→ 術前に詳しい検査と診察で安全に手術できるか判断。余病があっても術前に万全の準備で安全性の高い手術ができるようにしている。

7. 手術の合併症は？
→ 部位にもよるが代表的には脳梗塞・肺炎・対麻痺（下半身が動かなくなる）など。極力発生させないよう工夫し、事前に本人・家族にわかりやすく説明。

8. 人工血管で拒絶反応は起こる？
→ 術後に一過性の発熱はあり得るが、一般にいう拒絶反応はない。

9. 手術後、日常生活に制限は出る？
→ 普通の術後経過ではほとんどなし。必ず必要な内服薬もない。

10. 入院期間は？
→ 胸部大動脈瘤 約2週間／腹部大動脈瘤 約1週間／大動脈解離 約2〜3週間（術後も厳密な血圧管理が必要なため）。

11. 手術後どれくらいで仕事ができる？
→ 退院後約1〜2週間で外来受診があり、問題なければ翌日から仕事可能。傷の痛みが気にならなければ早期復職も可能。

12. 紹介状や検査結果がなくても受診できる？
→ 可能。どうぞお気軽に来院を。

13. 身内に大動脈瘤の人がいる。遺伝する？
→ 遺伝性は明確になっていないが家族内で発症することはある。生活習慣と関係があり、生活習慣が似ていると可能性が出ることも。不安があれば専門病院で相談を。

14. 大きな手術だが術後に寝たきりにならない？
→ 脳障害などの合併症がなければ寝たきりの一番の原因は長期臥床による筋力低下。手術翌日から専門スタッフが早期離床リハビリを開始し、適切な疼痛コントロールも行うので心配なし。

15. ステントグラフト治療を受けられない条件は？
→ 解剖学的に困難なケースがある。造影CTで詳細に評価。マルファン症候群など血管炎に伴う動脈瘤では禁忌とする意見あり。

16. ステントグラフト後、瘤から出ている枝はどうなる？
→ 多くは自然に詰まる。ただし残ってエンドリークの原因になることがあり、後でカテーテルによる塞栓術を追加することがある。

17. 60歳代でもステントグラフト治療を受けてよい？
→ 比較的若い方には従来の人工血管置換術を推奨。ただし心臓病・呼吸器疾患合併や開腹手術既往がある方などは年齢に関わらず適応となる場合あり。

18. CKD（腎機能が悪い）でも受けられる？
→ 人工血管置換術と比べ腎臓への負担は変わらない。造影剤量を減らす・輸液するなど腎機能が悪化しないよう工夫して治療。

19. ステントグラフト後、ワーファリンなど抗凝固薬は必要？
→ 必要なし。治療する血管が比較的太く血流量が多いため、基本的にワーファリンや抗血小板薬を必要としない。

20. 一度入ったら一生もの？
→ 新しい構造のグラフトで20年以上のデータはまだない。時間経過でずれることもあり定期的にCTで確認。検査は生涯続く。

21. 何日で普通の生活に戻れる？
→ 早期退院が可能。腹部大動脈瘤の場合、問題なければ5日ほどで退院。

22. 前後の放射線検査の被ばく量は問題ない？
→ 問題にならない。通常のCTより低い値で健康に害はない。ただし術後も定期CTが必要なため検査回数の管理に配慮。
