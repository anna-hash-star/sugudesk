| | 現状 | あるべき |
|---|---|---|
| 「HARG療法の料金を教えてください」 | 6回セット **349,200円** | **343,200円** |
| 「薄毛治療の料金を教えてください」（HARG部分） | 6回セット **349,200円** | **343,200円** |
