## ナレッジ（全件・事実主義）
- 拠点病院：2024年4月1日 愛知県がん診療拠点病院に指定。標準治療を行う。
- 治療4本柱：手術療法(定型〜肝膵食道など高難度・腹腔鏡積極導入・ロボット支援も導入)／薬物療法(がん薬物療法専門医が抗がん剤・分子標的薬・免疫療法をマネジメント・看護師薬剤師栄養士の指導)／放射線療法(全身の多くのがん・根治〜緩和・年齢全身状態の制限ゆるく小児〜高齢者)／緩和ケア(診断時から心身の苦痛緩和)。
- 対応がんと担当科：胃・肝・大腸・膵=消化器内科/消化器外科/腫瘍内科/肛門外科／肺=呼吸器内科/呼吸器外科／乳=乳腺外科/形成外科(乳房再建のみ)／前立腺・膀胱=泌尿器科／子宮頸=産婦人科／希少・小児・AYA・妊孕性温存・がんゲノム=がん相談支援センターで相談。症状治療により適した医療機関を紹介する場合あり。
- 遺伝性腫瘍外来(2024年4月新設)：HBOC(遺伝性乳がん卵巣がん)など。乳がん患者の約4〜5%・卵巣がん患者の約15%がHBOC、前立腺がん膵臓がんも発症しやすくなる。臨床遺伝専門医(遺伝性腫瘍専門医・暫定指導医)が担当(遺伝診療科)。
- がん相談支援センター：どなたでも無料・匿名。看護師・医療ソーシャルワーカーが患者家族の悩みを一緒に考え解決支援。
- セカンドオピニオン：当院以外を受診中の方に当院専門医が診療内容・治療方法の意見助言を提供(セカンドオピニオン外来)。
- 専門治療が必要ながんの連携先：希少がん/小児がん/AYA世代/がんゲノム医療/密封小線源・重粒子線治療 は愛知県がんセンター・名古屋大学医学部附属病院・岐阜大学医学部附属病院・名古屋医療センター等と連携紹介。
- その他：ACP(人生会議)、治験・臨床研究、市民公開講座、がん患者さま相談会(NPO法人ミーネット連携)、乳がん患者の会・Anzu Ring。がん罹患=年間新規約98万人・死亡約38万人・2人に1人が生涯でがん・男性は前立腺がん女性は乳がんが罹患数最多(厚労省 全国がん登録2021・人口動態2023)。

## FAQ
- がんの治療はどんなこと？→愛知県がん診療拠点病院として手術・薬物療法・放射線治療・緩和ケアの集学的治療(腹腔鏡・ロボット支援も導入)。
